## 数を0と1で表す
( 基数変換
- 10進→2進 — 整数は÷2の余りを**下から**、小数は×2の整数部を**上から**
- 2進⇔16進 — 4桁ずつ区切る（8進は3桁）
-* 0.1は2進で無限小数 — 有限で表せるのは分母が2のべき乗（0.5・0.375…）だけ
)
( シフト
- 左1ビット — 2倍。右1ビットで1/2
- 論理シフト — 符号を気にせず全部ずらす。空きは0
- 算術シフト — 符号ビットは固定。右シフトの空きは符号と同じ値
-* x×10 — 2ビット左（4x）＋x → 1ビット左。10＝(4＋1)×2
)
( 2の補数
- 作り方 — 全ビット反転して＋1
- なぜ使う — 引き算を「負の数を足す」にできる→加算回路だけでOK
-* nビットの範囲 — −2ⁿ⁻¹ 〜 2ⁿ⁻¹−1（8ビットなら−128〜127）
)
( 浮動小数点
- 形 — ±仮数×基数^指数
+* 正規化 — 仮数の先頭の0を消す。目的は**有効桁数を最大に**
+ IEEE754単精度 — 符号1＋指数8＋仮数23ビット。(−1)^s × 1.f × 2^(e−127)。「1.」は省略（ケチ表現）
)
@mx 演算の4つの誤差
x: 足し算・引き算で起きる | 有限で止める・丸めるときに起きる
y:  | 
TL: 情報落ち :: 大＋小で小が消える（1億＋1円）→小さい順に足す
TR: 打切り誤差 :: 無限の計算を途中で止めた
BL: 桁落ち :: ほぼ同じ数の引き算で有効桁が激減
BR: 丸め誤差 :: 有限ビットに収めるため四捨五入・切捨て
@end
> 情報落ち＝足し算、桁落ち＝引き算。これだけで即答できる

## 論理演算
(
- ド・モルガン — ¬(A∧B)＝¬A∨¬B。否定を中に入れると∧と∨が入れ替わる
+ A∨(B∧C)＝(A∨B)∧(A∨C) — 算数にない分配法則
+ カルノー図 — 真理値表をマス目にして、隣り合う1をまとめて式を簡単にする
- XOR — 違えば1（対称差）。XNOR＝同じなら1
)
( マスク
- AND — 0で消す（取り出す）
- OR — 1で塗る（1にする）
- XOR — 1で裏返す。A⊕B⊕B＝A（2回で元通り）→RAIDパリティ {{02-2}}・暗号
)

## 確率と分布
(
- 排反 — 同時に起きない → P(A∪B)＝P(A)＋P(B)
- 独立 — 影響しない → P(A∩B)＝P(A)×P(B)
+* ちょうどk回 — ₙCₖ × pᵏ × (1−p)ⁿ⁻ᵏ。RAID稼働率 {{02-2}}・OC曲線 {{06-2}} で使い回す
+ 少なくとも1回 — 1 −（1回も起きない確率）。不良率2%を3個 → 1 − 0.98³ ≒ 0.059
+* ベイズの定理 — **結果から原因の確率**を出す。「玉の色からどの袋か」「迷惑メール判定（ベイジアンフィルタ）」
)
= #+ ベイズ
= P(原因A｜結果N) ＝ P(A)×P_A(N) ÷ { P(A)×P_A(N) ＋ P(B)×P_B(N) }
=                    　└ Aを通ってNになる ┘   └ Nになる全ルートの合計 ┘
@fig normal | 正規分布 N(μ, σ²)
(
+* 正規分布 — 平均μと標準偏差σだけで形が決まる。±1σ 68%／±2σ 95%／±3σ 99.7%
+ 「90点以上が多い教科は？」 — (90−平均)÷σ が**小さい**ほど多い
)

## 待ち行列（M/M/1）
(
- M/M/1 — ランダムに来て（ポアソン到着）、処理時間も指数分布、窓口1つ、先着順、行列は無限
- ρ（利用率） — λ÷μ ＝ サービス時間÷到着間隔
)
= #平均待ち時間
= 平均待ち時間 ＝ ρ/(1−ρ) × 平均サービス時間
= 平均応答時間 ＝ 平均待ち時間 ＋ 平均サービス時間
= 例）処理4分・5分おきに来る → ρ＝0.8 → 待ち＝4×4＝16分 → 応答20分
@fig mm1 | 利用率と待ち時間
! ρ＝0.5で待ち時間＝サービス時間。「1時間に12人」みたいな率は到着間隔5分に直してから
! ρが1に近づくと待ち時間は**急増**（0.5で1倍、0.8で4倍、0.9で9倍）。「比例して増える」は誤り

## 形式言語・オートマトン
(
+ 文脈自由文法 G＝(T,N,P,S) — T終端記号・N非終端記号・P書換え規則・S開始記号。導出は1歩ずつ規則にあるか照合
+* BNF — `::=`で定義、`|`は「または」。**自分自身で定義（再帰）**できる。識別子＝英字で始まって後ろに付け足す形
+ 正規表現 — `|`または、`*`0回以上。記号の意味は問題文で定義されるのでその通りに当てはめる
+* 有限オートマトン — 入力を1文字ずつたどって、**最後が受理状態なら受理**。正規表現と同じ力
+ プッシュダウンオートマトン — 有限オートマトン＋スタック。文脈自由言語を受理
)

## 符号（誤り検出・圧縮）
( 誤りを見つける・直す
-* ハミング符号 — 4ビット＋検査3ビット。**2ビット検出・1ビット訂正**。検査式が1になった式全部に共通するビットが犯人
-* CRC — 生成多項式で割った余りを付ける。受信側も同じ多項式で割る。バースト誤りに強い・**訂正はできない**
- パリティ — 1の個数を偶数（奇数）に。奇数個の誤りしか分からない。垂直水平パリティなら1ビット訂正
)
( 縮める
+* ハフマン符号 — よく出る文字ほど短い符号。小さい2つをまとめる→を繰り返す。一意に復号できる
- ランレングス — AAAAABB→5A2B。同じ文字の連続に強い
)

= #平均ビット長
= Σ（符号の長さ × 出現率）＝ 1×0.5＋2×0.3＋3×0.1＋3×0.1 ＝ 1.7ビット

## デジタル化（PCM）
@flow 標本化::一定間隔で切る > 量子化::段階に丸める（8ビット＝256段階） > 符号化::2進数に || PCM：アナログ音→デジタル
(
-* 標本化定理 — 最高周波数の**2倍**でサンプリング（20kHz→40kHz、周期25μs）
+ DPCM — 前との差分だけ量子化
+ ADPCM — 差分のビット数を変動幅で変える。PCMの約**1/4**
)
= #データ量
= 音声 ＝ 標本化周波数 × 量子化ビット数 × チャネル数 × 秒数 ÷ 8 [バイト]
= 画像 ＝ 横画素 × 縦画素 × 1画素のビット数 ÷ 8
= 動画 ＝ 1フレーム × fps × 秒数
= 例）10kHz×16bit×4秒 ＝ 640kビット ＝ 80kバイト → ADPCMで1/4 → 20kバイト
! ビット→バイトの÷8忘れ。選択肢に8倍ずれたやつが必ずある

## AI（機械学習）
@stack 3つの学び方
教師あり :: 正解つきで学ぶ → 回帰（予測）・分類（決定木・ロジスティック）
教師なし :: 正解なし → クラスタリング・次元削減（主成分分析）
強化学習 :: 試行錯誤で**報酬**を最大化 → 将棋・ロボット
@end
(
- ニューラルネットワーク — 入力層→中間層→出力層。重みを調整して学習
+ 誤差逆伝播法 — 出力と正解の誤差が小さくなるよう重みを後ろから直す
+ 勾配降下法 — 誤差が減る向きに少しずつ重みを動かす
+* ディープラーニング — 中間層が多層（DNN）。CNN＝画像、RNN＝時系列（翻訳・音声）
+ 活性化関数 — ReLU（0以下は0）、シグモイド（0〜1になめらかに）
+* 過学習 — 訓練データに合わせすぎて未知データに弱い。対策：データ増・ドロップアウト・正則化
+ 汎化性能 — 未知データでも当たる力（過学習の反対）
+ 交差検証 — k個に分けて検証用を入れ替えながら評価
+* GAN — 生成（偽物を作る）と識別（見破る）を競わせる
+ 転移学習 — 学習済みモデルを別の課題に流用
+ アンサンブル — バギング（並列→多数決、ランダムフォレスト）／ブースティング（前の誤りを次が重点学習）
+ アノテーション — 教師データに正解ラベルを付ける作業
+ ハルシネーション — 生成AIがもっともらしいウソを出す
- エキスパートシステム — 知識ベース（もし〜ならば）＋推論エンジン
)
! 「ルールで推論」＝エキスパートシステム、「データから規則を発見」＝データマイニング {{03-2}}
| 混同行列 | 正解：陽性 | 正解：陰性 |
| 予測：陽性 | TP | FP（誤検知） |
| 予測：陰性 | FN（見逃し） | TN |
= #+ AIの評価指標
= 適合率 ＝ TP ÷ (TP＋FP)    …「陽性と予測した中の当たり」＝予測側が分母
= 再現率 ＝ TP ÷ (TP＋FN)    …「本物の陽性を何割拾えたか」＝正解側が分母
= F値   ＝ 2×適合率×再現率 ÷ (適合率＋再現率)
> 誤検知・検知漏れはIDS {{03-5}}、本人拒否・他人受入は生体認証 {{03-6}} で同じ形がまた出る

## データ構造
( リスト
- 配列 — 連続に並ぶ。番号で一発参照、挿入削除は遅い
- リスト — ポインタでつなぐ。挿入削除はポインタ付け替えだけで速い
+* 単方向リストで一番重い操作 — **末尾の削除**（1つ前を知るのに先頭からたどる）
)
( スタックとキュー
-* スタック — LIFO（後入れ先出し）。push/pop。**再帰・関数の戻り番地・逆ポーランド計算・深さ優先**
-* キュー — FIFO（先入れ先出し）。enqueue/dequeue。幅優先・待ち行列
+ リングバッファ — 末尾の次は先頭へ。x＝(x＋1) mod 要素数
+ 逆ポーランドをスタックで — 数字はpush、演算子で2つpopして計算。先にpopした方が**右側**
)
> 「再帰」と来たら「スタック（LIFO）」

## 木
@fig traversal | 2分木の走査
(
-* 2分探索木 — 左＜節＜右。探索は根から比べて左右へ
+ 2分探索木の削除 — 子が2つなら「左の最大」か「右の最小」で埋める
- 偏った木 — O(n)。完全2分木ならO(log₂n)
+* 完全2分木 — 葉がN個なら葉以外はN−1個。深さHで葉2ᴴ個。節点数＝枝数＋1
+ AVL木 — 左右の高さの差1以下に保つ
+* B木 — 多分木。DBのインデックス（B⁺木）{{03-2}}
+ ヒープ — 親≦子（or ≧）の木を配列で。A[i]の子はA[2i]・A[2i+1]
)

## 探索
(
-* 線形探索 — 先頭から順番。平均(n＋1)/2回、O(n)。整列不要
-* 2分探索 — 整列済みが条件。真ん中と比べて半分捨てる。O(log₂n)
+ 2分探索の最大比較回数 — ⌊log₂n⌋＋1（1000個なら10回。データ2倍でも＋1回）
-* ハッシュ探索 — キーから格納場所を計算。O(1)
+* 衝突（シノニム） — 違うキーで同じハッシュ値。x mod nなら「a−bがnの倍数」で衝突
+ 衝突の解決 — オープンアドレス法（別の場所を計算し直す）／チェイン法（リストでつなぐ）
+ 深さ優先／幅優先探索 — **スタック**で行けるところまで進んで戻る／**キュー**で近い順（重みなしの最短経路）
+ ダイクストラ法 — 重みが負でないグラフの**最短経路**
)
> ハッシュはこの先、署名 {{03-5}}・パスワード保存 {{03-6}}・ブロックチェーン {{03-2}} で使い回される

## 整列
| 方法 | しくみ | 計算量 |
| バブル | 隣と交換してく | O(n²) |
| 選択 | 最小を選んで先頭と交換 | O(n²) |
| 挿入 | 整列済みの正しい位置に入れてく | O(n²)、最良O(n) |
+| シェル | 間隔おきに挿入ソート→間隔を詰める | 改良挿入 |
+| クイック | 基準値で大小に分けて再帰 | 平均O(n log n)、最悪O(n²) |
+| マージ | 半分に割り続けて併合 | O(n log n)、作業領域が要る |
+| ヒープ | 根（最小/最大）を取り出してヒープを再構成 | O(n log n) |
! 整列済みデータで挿入ソートは比較n回でO(n)。クイックは整列済みで端を基準にするとO(n²)
! **安定**（同じキーの元の並びが保たれる）なのはバブル・挿入・マージ。選択・シェル・クイック・ヒープは不安定

## プログラムとメモリ
(
- 値呼出し — コピーを渡す。中で変えても呼び出し元は変わらない
- 参照呼出し — アドレスを渡す。呼び出し元も変わる
+ 再帰のトレース — 一番深い呼出しまで書き下して、戻りながら計算
+ auto変数 — 関数終了で消える。static変数＝プログラム終了まで（初期化1回）
+ ヒープ領域 — 実行中に動的に確保・解放。繰り返すとフラグメンテーション→**ガーベジコレクション**で回収
- スタック領域 — 戻り番地・局所変数・引数
)
@lad 3つの「〜可能」 | 何ができる？ |
再帰可能（リカーシブ） :: 自分で自分を呼べる → スタックに戻り番地・局所変数
再入可能（リエントラント） :: **同時に**複数から呼ばれてもOK → 手続部とデータ部を分け、データ部を呼出し元ごとに
再使用可能（リユーザブル） :: ロードし直さず**繰り返し**使える → 最初か最後に初期化（同時は不可）
再配置可能（リロケータブル） :: どこに置いても動く
@end
