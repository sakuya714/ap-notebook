@box goal
1. 識別関数 $g(\vx)=\vw^{t}\vx$ の意味を言える

## なぜ直線で分けられる？
点の集まりを「どっち側か」で分けたい。直線の式に点を入れると、片側ではプラス、反対側ではマイナスになる。だから符号を見るだけで判定できる。
$$ g(\vx) = \vw^{t}\vx = w_0 + w_1x_1 + w_2x_2 \tag{1.17} $$
@fig line_split | 直線で分ける | 金の点は g>0、青緑の点は g<0
@box why なぜ符号で決まる？
直線上では $g=0$。そこから離れるほど $|g|$ が大きくなり、向きで符号が変わる。
@end
@box warn
$g=0$（境界ぴったり）は「正解」ではない。**0 も修正する**。
@end
@steps 重みの更新
間違えた点を見つける :: g の符号が答えと逆
w に ρ b x を足す :: 答えの向きに少し動かす
全部正しくなるまで繰り返す
@end
@fold 導出（自分で考えてから開く）
$\vw' = \vw + \rho b\vx$ を代入すると $b\,g'(\vx) = b\,g(\vx) + \rho\lVert\vx\rVert^2$ 。右の項は必ず正なので、間違いが直る方向に動く。∎
@end
@quiz ρ を大きくするとどうなる？
1回で大きく動くので速いが、行き過ぎて振動しやすい。
@end
@ox
○ 境界ぴったり（g=0）の点も修正する :: 0 は正解ではないから
× 分けられないデータでも必ず止まる :: 分けられないなら止まらない
@end
@check
識別関数の符号の意味を言える
更新式を1回手で回せる
@end
```
w = w + rho * b * x   # 間違えたら答えの向きに動かす
```
