## ○×（選択問題の練習）
@ox 正しければ○、間違いなら×
○ 特徴抽出部は識別に有効な特徴を取り出す部分で、入力データの種類によって処理の中身が変わる :: 第1回。ノイズ除去・正規化は前処理部、クラスの判定は識別部
× 最近傍決定則は、学習パターンのクラスに誤りがあっても影響を受けにくい :: 逆。1個の誤りにも引っぱられる（学習パターンに過度に適合）。k 最近傍法で和らげる
○ 見本がクラスに1個ずつの最近傍決定則は、線形識別関数による識別と等価である :: $g_i(\vx)=\vp_i^t\vx-\frac12\lVert\vp_i\rVert^2$。距離の2乗を展開して、共通の $\lVert\vx\rVert^2$ を捨てる
× パーセプトロンの学習規則は、すべてのパターンについて毎回重みを修正する :: 正しく識別できないとき（$b_kg(\vx_k)\le0$）だけ修正する誤り訂正法
× パーセプトロンは、線形分離不可能な学習パターンでも有限回で収束する :: 有限回で止まるのは線形分離可能なときだけ。不可能だと修正を永遠にくり返す
○ パーセプトロンで得られる決定境界は、学習パターンを与える順序によって変わる :: 寄与ベクトルも順序で変わり、境界は一意に決まらない
× マージンを有する線形識別関数を使えば、最適な決定境界が必ず得られる :: 未知パターンへの性能向上は期待できるが、最適の保証はない
○ ベイズ識別関数は $P(\omega_i)p(\vx\mid\omega_i)$ が最大のクラスを選ぶ :: 事後確率最大と同じ。$p(\vx)$ は全クラス共通なので捨ててよい
× フィッシャーの方法は、クラス内変動が大きく、クラスの平均の差が小さくなる向きを求める :: 逆。クラス内変動は小さく、平均は離れる向き（$J(\vw)$ を最大化）
○ 二乗誤差最小化学習は、識別関数の値と教師信号の誤差の2乗和を最小にする :: $\vw=(\vX^t\vX)^{-1}\vX^t\vb$。逆行列が重いときは最急降下法
× 一般化線形識別関数は、$x$ について線形、$\phi$ について非線形である :: 逆。$x$ について非線形、$\phi$ について線形
○ Φ関数の選び方に明確な指針がなかったため、一般化線形識別関数は広く使われなかった :: 第4回のまとめ。カーネルにも「選択に明確な指針がない」という同じ弱点が残る
× ポテンシャル関数法は、必ずすべての学習パターンを正しく識別できる :: できるとは限らない。全パターンでポテンシャルの和を取るので処理量も膨大
○ ポテンシャル関数法とパーセプトロンには双対の関係がある :: $K(\vx,\vx_k)=\vphi(\vx_k)^t\vphi(\vx)$ なら同じ識別関数になる
× SVM は $\frac12\lVert\vw\rVert^2$ を最大化してマージンを最大にする :: 最小化。$R=2/\lVert\vw\rVert$ なので、$\lVert\vw\rVert$ が小さいほどマージンは大きい
○ サポートベクトルは、双対問題の解で $\lambda_k^*>0$ となる学習パターンである :: 決定境界に最も近く、重みの決定に寄与する
× SVM の解は、学習パターンを与える順序によって変わる :: 凸二次計画問題なので大域的最適解が保証され、解は一意に決まる
× ソフトマージンSVM の重み係数 $c_{pe}$ は、学習によって自動で決まる :: あらかじめ人が決めるハイパーパラメータ
○ カーネル関数を定めれば、非線形写像 $\vphi$ そのものは未定義でもよい :: 双対問題には内積 $\vphi(\vx_i)^t\vphi(\vx_j)$ しか出てこないから
× SVM は、そのままで3クラス以上を識別できる :: できない。2クラス用を組み合わせる
× RBF カーネルの $\gamma$ を大きくすると、決定境界はなめらか（直線に近く）になる :: 逆。$\gamma$ が大きいと1点ごとに巻きつく複雑な境界になる
@end

$g_i=\vp_i^t\vx-\frac12\lVert\vp_i\rVert^2$ より $g_1=2x_2-2$、$g_2=2x_1-2$。
$\vx=(2,1)$：$g_1=0$、$g_2=2$ → $\omega_2$。

@quiz 8. SVM の解が $g(\vx)=2x_1+x_2-3$ のとき、マージン $R$ は？ 点 $(2,0)$ と $(1,1)$ はそれぞれどこにいる？
$\lVert\vw\rVert=\sqrt5$ → $R=2/\sqrt5\approx0.894$。
$(2,0)$：$g=1$ → マージンの端の線の上（サポートベクトルになりうる）。境界との距離 $1/\sqrt5\approx0.447$ ＝ $R/2$。
$(1,1)$：$g=0$ → 決定境界の上（学習パターンならハードマージンの条件 $bg\ge1$ を破る位置）。
@end
@quiz 9. SVM を手計算せよ：$\vx_1=(2,2)^t,\ b_1=1$、$\vx_2=(0,0)^t,\ b_2=-1$
1. $\lambda_1-\lambda_2=0$ → $\lambda_1=\lambda_2=\lambda$
2. $\vw=\lambda(2,2)-\lambda(0,0)=(2\lambda,\ 2\lambda)$、$\lVert\vw\rVert^2=8\lambda^2$
3. $L=2\lambda-\frac12\cdot8\lambda^2=2\lambda-4\lambda^2$、$\dfrac{dL}{d\lambda}=2-8\lambda=0$ → $\lambda=\frac14$
4. $\vw=(\frac12,\frac12)$、$w_0=b_1-\vw^t\vx_1=1-2=-1$
$g(\vx)=\frac12x_1+\frac12x_2-1$（境界は $x_1+x_2=2$）。検算 $g(\vx_2)=-1=b_2$ ✓。$R=2/\lVert\vw\rVert=2\sqrt2$（2点の距離と一致 ✓）。原点の点があると $w_0\ne0$ になる。
@end

## 記述
@quiz A. SVM で、主問題ではなく双対問題を解く理由を2つ書け
1. 条件が簡単に書ける（$\vlam\ge0$ と $\vlam^t\vb=0$ だけ。主問題は不等式が $n$ 本）
2. データが内積 $\vx_i^t\vx_j$ の形でしか出てこないので、内積をカーネル関数に取り替えて非線形SVM にできる
@end
@quiz B. サポートベクトルとは何か。KKT 条件と結びつけて説明せよ
KKT 条件の $\lambda_k\bigl(b_k(w_0+\vw^t\vx_k)-1\bigr)=0$ から、各学習パターンは「$\lambda_k=0$」か「$b_k(w_0+\vw^t\vx_k)=1$（マージンの端の線の上）」のどちらか。
$\lambda_k^*>0$ となるパターンがサポートベクトルで、決定境界に最も近く、$\vw=\sum\lambda_k^*b_k\vx_k$ の決定に寄与する。$\lambda_k^*=0$ のパターンは重みに効かない。
@end
@quiz C. カーネル法の利点を、「高次元」「内積」という言葉を使って説明せよ
非線形写像で高次元空間に写せば複雑な決定境界を表現できるが、SVM（双対問題）で必要なのは写した先の**内積**だけ。カーネル関数 $k(\vx,\vy)=\vphi(\vx)^t\vphi(\vy)$ を使えば、**高次元**での内積の計算を原空間での計算で代えられ、写像 $\vphi$ 自体を定める必要もない。
@end
@quiz D. SVM を利用する上での留意点を4つ書け
1. そのままでは3クラス以上の識別ができない
2. 凸二次計画法を解く計算量に注意が必要
3. 重み係数 $c_{pe}$（やカーネルの $\gamma$ など）はあらかじめ設定する必要がある（ハイパーパラメータ）
4. クラスによって学習パターンに大きな偏りがある場合に注意が必要（クラスごとに $c_{pe}$ を変えるなど）
（第7回では「カーネル関数の選択に明確な指針がない」も挙がっている）
@end
@quiz E. パーセプトロンとハードマージンSVM で、決定境界の決まり方はどう違うか
パーセプトロンは、間違えたパターンを足していき、全部正しく分けられた所で止まる。どこで止まるかはパターンを与える順序しだいで、境界は一意に決まらず、境界すれすれの点が残ることもある。
ハードマージンSVM は、全部を正しく分ける境界の中からマージン $R=2/\lVert\vw\rVert$ が最大のものを、凸二次計画問題として解く。解は一意で、サポートベクトルだけで決まり、汎化能力が高いと期待できる。
@end
