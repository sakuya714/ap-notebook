## 非線形識別関数：2次の項を足す
$$ g(\vx)=\vw^t\vx=\sum_{j=0}^{d}w_jx_j\quad(x_0\equiv1)\tag{3.2} $$
$d=2$ なら $g(\vx)=w_0+w_1x_1+w_2x_2$（3.3）で直線。ここに2次の項を足すと
$$ \begin{aligned}g(\vx)=\ &w_0+w_1x_1+w_2x_2\\&+w_3x_1x_2+w_4x_1^2+w_5x_2^2\end{aligned}\tag{3.4} $$
**2次識別関数**（非線形識別関数の1つ）になり、境界は円・楕円・双曲線のような曲線になれる。3次、4次…と足したものをまとめて**多項式識別関数**と呼ぶ。

## Φ関数で一般化：一般化線形識別関数
式 (3.4) の各項を「$\vx$ の関数」と見て、名前を付け直す。
$$ \Phi(\vx)=\sum_{j=1}^{D}w_j\phi_j(\vx)\tag{3.6} $$
例えば $\phi_1(\vx)=x_0=1$、$\phi_2(\vx)=x_1$、$\phi_3(\vx)=x_2$、$\phi_4(\vx)=x_1x_2$、$\phi_5(\vx)=x_1^2$、$\phi_6(\vx)=x_2^2$ とすると (3.4) そのもの。
この関数は $x_1,\dots,x_d$ については**非線形**（2乗や掛け算がある）だが、$\phi_1(\vx),\dots,\phi_D(\vx)$ については**線形**（重みを掛けて足しているだけ）。これを**一般化線形識別関数**、これで識別することを**一般化線形識別関数法**と呼ぶ。
= #+一般化線形識別関数（3.19〜3.24）
= $\vw=(w_1,\dots,w_D)^t$
= $g(\vx)=\Phi(\vx)=\sum_{j=1}^{D}w_j\phi_j(\vx)=\vw^t\vphi(\vx)$
= $g>0\Rightarrow\omega_1$、$g<0\Rightarrow\omega_2$、境界 $g(\vx)=0$
@box exam 試験で取る
去年は「一般化線形識別関数は何について線形か」が出た。答えは **$x$ について非線形、$\phi$ について線形**。逆にした選択肢がひっかけ。
@end

## 原空間とΦ空間：写すと直線で分かれる
$\vphi(\vx)=(\phi_1(\vx),\dots,\phi_D(\vx))^t$ が住む $D$ 次元空間を**Φ空間**、元の $\vx$ の空間を**原空間**と呼ぶ。
例：半径1の円の上に $\omega_2$、半径3の円の上に $\omega_1$ が並んでいる。原空間ではどう直線を引いても分けられない。そこで $\phi_1(\vx)=x_1^2,\ \phi_2(\vx)=x_2^2$ と写すと
| | 原空間 | Φ空間 |
| $\omega_2$（内側） | $x_1^2+x_2^2\approx1$（円） | $\phi_1+\phi_2\approx1$（直線） |
| $\omega_1$（外側） | $x_1^2+x_2^2\approx9$（円） | $\phi_1+\phi_2\approx9$（直線） |
Φ空間では2本の平行な直線に並ぶので、間に直線 $\phi_1+\phi_2=5$ を引けば分かれる。識別関数は $g(\vx)=\phi_1(\vx)+\phi_2(\vx)-5$（定数項 $-5$ が $w_0$ の役）。
検算：$(1,0)$ は $1-5=-4<0$ → $\omega_2$ ✓、$(3,0)$ は $9-5=4>0$ → $\omega_1$ ✓、$(2,1)$ は $4+1-5=0$ → ちょうど境界。原空間に戻すと境界は $x_1^2+x_2^2=5$、**半径 $\sqrt5$ の円**。
@fig! phi_circle | 原空間とΦ空間 | 左：原空間では直線では分けられない。右：φ₁＝x₁²、φ₂＝x₂² で写すと2本の直線に並び、φ₁＋φ₂＝5 で分かれる。その直線を原空間に戻すと、左の半径√5 の円になる
原空間で線形分離できなくても、Φ空間では線形分離できることがある。そしてΦ空間の中では「直線を前提にした手法」がそのまま使える。

## 基本パーセプトロン：Φ空間でパーセプトロン
第2回の学習規則の **$\vx$ を $\vphi(\vx)$ に置き換えるだけ**。$D$ 次元のΦ空間で2クラスが線形分離可能なら、有限回で正しい $\vw$ が得られる。
@steps 基本パーセプトロンの学習規則（$\vw$ の更新をくり返す）
$d$ 次元から $D$ 次元への非線形変換 $\vphi(\vx)$ を決める :: 何に写すかは人が決める
学習パターン $\vx_1,\dots,\vx_n$ と教師信号 $b_1,\dots,b_n$ を用意し、$\vw$ の初期値を決める :: 第2回と同じ
パターン $\vx_k$ を選んで $g(\vx_k)=\vw^t\vphi(\vx_k)$ を求める :: (3.25)
$b_kg(\vx_k)\le0$ なら $\vw'=\vw+\rho\,b_k\vphi(\vx_k)$、それ以外はそのまま :: (3.26)
全部正しく識別できたら終了。でなければ別のパターンでくり返す :: 第2回と同じ
@end
$\rho=1$・初期値 $\mathbf{0}$ なら、第2回と同じく最後の $\vw$ は足し算になる。
$$ \vw=\sum_{k=1}^{n}\alpha_kb_k\vphi(\vx_k)\tag{3.27} $$
$$ g(\vx)=\sum_{k=1}^{n}\alpha_kb_k\,\vphi(\vx_k)^t\vphi(\vx)\tag{3.28} $$
$\alpha_k$ は第2回と同じ誤り計数ベクトルの要素（$\vx_k$ で修正した回数）。

## 双対パーセプトロン：w の代わりに α を学習する
同じ識別関数が、2通りの形で書けている。
| | 基本パーセプトロン | 双対パーセプトロン |
| 識別関数 | $g(\vx)=\vw^t\vphi(\vx)$（3.22） | $g(\vx)=\sum_k\alpha_kb_k\vphi(\vx_k)^t\vphi(\vx)$（3.28） |
| 学習する量 | $\vw$（$D$ 個の数） | $\valpha$（$n$ 個の数） |
| 間違えたとき | $\vw'=\vw+\rho\,b_k\vphi(\vx_k)$ | $\alpha_k'=\alpha_k+1$（3.31） |
| 使う計算 | $\vphi(\vx)$ そのもの | $\vphi(\vx_i)^t\vphi(\vx_k)$（内積だけ） |
**双対関係**（＝同じ内容を、異なる2通りの形式で表現できること）。双対パーセプトロンは、誤り計数ベクトル $\valpha$ をパラメータとして学習する：初期値 $\valpha=\mathbf{0}$（3.29）、$g(\vx_k)=\sum_i\alpha_ib_i\vphi(\vx_i)^t\vphi(\vx_k)$（3.30）を計算し、$b_kg(\vx_k)\le0$ なら $\alpha_k$ を1増やす（3.31）。
第2回の例題で確かめる（$\vphi(\vx)$＝拡張した $\vx$ そのもの、$\valpha=(3,4,2,5)$）。新しい点 $\vx=(3,1)$（拡張 $(1,3,1)$）で：
| k | $\alpha_k$ | $b_k$ | $\vx_k^t\vx$ | $\alpha_kb_k\vx_k^t\vx$ |
| 1 | 3 | +1 | 1+3+1＝5 | 15 |
| 2 | 4 | −1 | 1+3+2＝6 | −24 |
| 3 | 2 | −1 | 1+6+3＝10 | −20 |
| 4 | 5 | +1 | 1+6+1＝8 | 40 |
合計 $15-24-20+40=11$。基本形で $\vw^t\vx=(2,5,-6)\cdot(1,3,1)=2+15-6=11$ と一致 ✓。
@box why なぜわざわざ双対の形にする？
双対の形には、$\vphi$ が**内積** $\vphi(\vx_i)^t\vphi(\vx_k)$ の形でしか出てこない。Φ空間の次元 $D$ がものすごく大きくても、内積さえ安く計算できれば学習できる。これが第7回のカーネル法の種。
@end
@box exam 試験で取る（Φ関数の弱点）
$\phi_1(\vx),\dots,\phi_D(\vx)$ の**選び方に明確な指針がなかった**ので、一般化線形識別関数は広く使われることはなかった（去年の選択問題）。第7回でも「カーネル関数の選択に明確な指針がない」と同じ弱点が残る。
@end

## ポテンシャル関数法：原空間で直接、曲がった境界を作る
電荷のたとえ。$\omega_1$ の学習パターンを＋の電荷、$\omega_2$ を−の電荷と思うと、点 $\vx$ には全部の電荷からの**静電ポテンシャル**（＝電荷が作る「高さ」。近いほど強い）の合計がかかる。それを識別関数として扱う。
$$ g(\vx)=\sum_{k=1}^{n}q_k\cdot K(\vx,\vx_k)\tag{4.1} $$
$K(\vx,\vx_k)$ を**ポテンシャル関数**（＝$\vx_k$ を中心にした山。$\vx$ が近いほど大きい）と呼び、ガウス関数（釣鐘型の山）がよく使われる。$q_k$ はその山の高さと符号。
@steps ポテンシャル関数法の学習アルゴリズム
ポテンシャル関数 $K(\vx,\vx_k)$ を定める :: 山の形（ガウス関数なら幅 σ）を決める
学習パターンと教師信号を用意し、誤り計数ベクトルを $\valpha=\mathbf{0}$ にする :: (4.10)
パターン $\vx_k$ を選んで $g(\vx_k)=\sum_i\alpha_ib_iK(\vx_k,\vx_i)$ を求める :: (4.11)
$b_kg(\vx_k)\le0$ なら $\alpha_k'=\alpha_k+1$、それ以外はそのまま :: (4.12)
全部正しく識別できたら終了。でなければくり返す :: 双対パーセプトロンとまったく同じ形
@end
つまり $q_k=\alpha_kb_k$。双対パーセプトロンの $\vphi(\vx_i)^t\vphi(\vx_k)$ を $K$ に取り替えただけ。
山の幅 σ が小さいと、1点1点のまわりだけが盛り上がり、境界はぐにゃぐにゃになる（**全数記憶の最近傍決定則に近い**）。σ が大きいと、なめらかな境界になる。
| | 一般化線形識別関数法（第3章） | ポテンシャル関数法（第4章） |
| やり方 | 高次元空間に写像して、そこで線形識別 | 原空間で直接、非線形の識別関数を求める |
| 決めるもの | 写し方 $\vphi$ | 山の形 $K$ |
**問題点**：必ずしもすべての学習パターンを正しく識別できない。すべての学習パターンについてポテンシャル関数の和を計算するので、処理量が膨大になる。

## 双対性：ポテンシャル関数法 ＝ Φ空間のパーセプトロン
| 形 | 式 |
| ポテンシャル関数法 | $g(\vx)=\sum_k\alpha_kb_kK(\vx,\vx_k)$（4.9） |
| ↓ $K$ を内積にする | $K(\vx,\vx_k)=\vphi(\vx_k)^t\vphi(\vx)$（4.13） |
| 双対パーセプトロン | $g(\vx)=\sum_k\alpha_kb_k\vphi(\vx_k)^t\vphi(\vx)$（4.15） |
| ↓ $\vw$ にまとめる | $\vw=\sum_k\alpha_kb_k\vphi(\vx_k)$（4.17） |
| パーセプトロン | $g(\vx)=\vw^t\vphi(\vx)$（4.18） |
上から読むとポテンシャル関数法がパーセプトロンになり、下から読むとその逆。$K$ が $\vphi$ の内積として書けるなら、2つは**同じ識別関数**（双対の関係）。大事なのは「非線形変換 $\vphi$ そのものではなく、**その内積**を求めれば良い」ということ。

## 生成モデルと識別モデル
| | 生成モデル | 識別モデル |
| やること | パターンが従う確率分布を精度良く推定する | 識別関数を直接表現して求める |
| 例 | ベイズ識別関数（$p(\vx\mid\omega_i)$ を推定して使う） | パーセプトロン・二乗誤差・ポテンシャル関数法・SVM |
分布が分かればベイズ識別が最良だが、分布の推定そのものが難しい。だから識別関数を直接求める識別モデルが使われる。

@quiz $\phi_1=x_1^2,\ \phi_2=x_2^2$ で、半径2の円の上に $\omega_2$、半径4の円の上に $\omega_1$ があるとき、Φ空間で真ん中を通る直線と、原空間での境界を答えよ。$(3,1)$ と $(1,2)$ はどうなる？
Φ空間では $\phi_1+\phi_2=4$ と $16$ の直線に並ぶので、真ん中は $\phi_1+\phi_2=10$、$g(\vx)=\phi_1+\phi_2-10$。原空間では $x_1^2+x_2^2=10$、半径 $\sqrt{10}$ の円。
$(3,1)$：$9+1-10=0$ → ちょうど境界の上。$(1,2)$：$1+4-10=-5<0$ → $\omega_2$（内側）。
@end
@check
「$x$ について非線形、$\phi$ について線形」の意味と、だから直線用の道具が使えることを言える
円の例で、Φ空間の直線 $\phi_1+\phi_2=5$ が原空間の半径 $\sqrt5$ の円になることを示せる
基本パーセプトロンと双対パーセプトロンの違い（学習する量・更新式・使う計算）を言える
ポテンシャル関数法の更新式が双対パーセプトロンと同じ形で、$K=\vphi$ の内積なら同じものになることを言える
生成モデルと識別モデルの違いを言える
@end
だから次は：パーセプトロンもポテンシャル関数法も、全部正しく分ける境界の中から「どれが一番いいか」を選ぶ基準を持たない。**一番いい1本**を決める基準を作る（{{05}} SVM）。
