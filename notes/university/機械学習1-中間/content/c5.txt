## 汎化能力：未知のデータで正しく分けられるか
**汎化能力**（＝学習に使っていない未知のパターンを、正しく識別できる能力）。学習パターンを全部正しく分けられても、未知パターンで間違えるなら意味がない。第2回で見たとおり、境界とのあいだに余裕（マージン）がある方が汎化能力を高められると期待できる。
| 種類 | 使うもの | 前提 |
| ハードマージンSVM | 線形識別関数 | 学習データが線形分離**可能**（この回） |
| ソフトマージンSVM | 線形識別関数 | 線形分離**不可能**でもいい（第6回） |
| 非線形SVM | 線形識別関数＋カーネル | 境界を曲げる（第7回） |
上の2つをまとめて線形サポートベクトルマシンと呼ぶ。
@box warn SVM では $w_0$ をまた外に出す
第2〜4回は拡張ベクトルで $g(\vx)=\vw^t\vx$ と書いたが、SVM では $g(\vx)=w_0+\vw^t\vx$ と**バイアスを分けて書く**。$\vw$ に $w_0$ は入っていない。マージンの大きさを決めるのは $\vw$ だけだから（$w_0$ は境界を平行にずらすだけ）。
@end

## マージンの式：点と境界の距離
パターン $\vx_k$ と決定境界 $g(\vx)=0$ の距離は（{{00}} で導いた式、教科書の式 (1.40)）
$$ r_k=\frac{\lvert g(\vx_k)\rvert}{\lVert\vw\rVert} $$
すべての学習パターンが、境界から $R/2$ 以上離れていてほしい（$R$ がマージンの幅）。正しく分けられているなら $\lvert g(\vx_k)\rvert=b_kg(\vx_k)$ なので
$$ r_k=\frac{b_k(w_0+\vw^t\vx_k)}{\lVert\vw\rVert}\ \ge\ \frac R2\quad(k=1,\dots,n) $$
ここで、$w_0$ と $\vw$ を全部同じ倍率で何倍しても境界 $g=0$ は変わらない。そこで「境界に一番近いパターンで $b_kg(\vx_k)$ がちょうど 1 になる」ように倍率をそろえる（5.6）。すると条件はこう書ける。
$$ b_k(w_0+\vw^t\vx_k)\ \ge\ 1\quad(k=1,\dots,n) $$
一番近いパターンでは $r_k=1/\lVert\vw\rVert$（5.7）なので、マージンの幅は $R=2/\lVert\vw\rVert$（5.8）。
= #+ハードマージンSVM（線形分離できる場合）
= 条件：$b_k(w_0+\vw^t\vx_k)\ge1\quad(k=1,\dots,n)$
= 目的：$\min_{\vw}\ \frac12\lVert\vw\rVert^2$
= （マージン $R=\dfrac{2}{\lVert\vw\rVert}$ を最大にするのと同じ）
| 記号 | 意味 |
| $b_k$ | 教師信号（$+1$ か $-1$） |
| $\vx_k$ | 特徴ベクトル（拡張しない） |
| $R$ | マージン（境界の両側の余裕を合わせた幅） |
| $r_k$ | パターン $\vx_k$ と境界の距離 |
@box why なぜ「$R$ を最大化」が「$\frac12\lVert\vw\rVert^2$ を最小化」になる？
$R=2/\lVert\vw\rVert$ を大きくする ⇔ $\lVert\vw\rVert$ を小さくする ⇔ $\lVert\vw\rVert^2$ を小さくする（ルートが消えて微分しやすい）。$\frac12$ は、微分すると $\vw$ だけが残ってきれいになるため（{{00}}）。
@end
@box exam 試験で取る
「SVM は $\frac12\lVert\vw\rVert^2$ を**最大化**する」はひっかけ（去年の選択問題）。正しくは**最小化**。
@end
@fig margin | マージンとサポートベクトル（第6回の手計算の3点） | 答えは g＝½x₁＋½x₂。x₁ と x₂ がマージンの端 g＝±1 の線に乗っている（サポートベクトル）。x₃ は外側にいて、境界の位置に効かない。青緑の破線が x₁ と境界の距離 r＝1/‖w‖＝√2
これは**条件付き極値問題**（＝条件を守りながら最小を探す問題）。しかも目的が2次式・条件が1次式なので**凸二次計画問題**（＝谷が1つしかない、解きやすい最適化問題）になる。解き方がラグランジュの未定乗数法。

## ラグランジュの未定乗数法：条件付きで最小を探す道具
いったん SVM を離れて、一般の形で考える。$f(x,y)$ を最小化したい。ただし条件 $g(x,y)\le0$ を守る。（ここの $g$ は識別関数ではなく、制約を表す関数。スライドの記号のまま）
**勾配** $\nabla f=\left(\dfrac{\partial f}{\partial x},\dfrac{\partial f}{\partial y}\right)$（ナブラ）は、$f$ が一番増える向きを向き、等高線に直交する。
@fig! lagrange | 最小点が条件の領域の中か外か | 左：f の最小点が g≤0 の中にある → 条件は関係なく ∇f＝0 で解ける。右：外にある → 領域の境界の上で、f の等高線と境界が接する所が最適解。そこでは ∇f と ∇g が逆向き：∇f＝−α∇g（α＞0）
2つの場合を1本にまとめるのが**ラグランジュ関数**と **KKT 条件**。
= #+ラグランジュ関数と KKT 条件
= $L(x,y,\alpha)=f(x,y)+\alpha\,g(x,y)$
= $\nabla L=0,\quad \alpha\ge0,$ $\quad\alpha\,g(x,y)=0,\quad g(x,y)\le0$
$\alpha\,g=0$ だから、$\alpha=0$ か $g=0$ のどちらか。$\alpha=0$ なら $\nabla L=\nabla f=0$（左の場合）。$g=0$ なら境界の上で $\nabla f=-\alpha\nabla g$（右の場合）。KKT 条件は2つの場合を両方含んでいる。$\alpha$ を**ラグランジュ乗数**と呼ぶ。
@box why なぜ $\alpha g=0$（相補性）？
条件が効いていない（最小点が内側）なら、条件の重み $\alpha$ は 0 でいい。条件が効いている（境界ぴったりで止められている）なら $g=0$。どちらか片方は必ず 0 になる。SVM ではこれが「サポートベクトル以外は $\lambda=0$」の正体になる。
@end

## SVM に当てはめる
条件が $n$ 本あるので、ラグランジュ乗数も $\lambda_1,\dots,\lambda_n$ の $n$ 個。
$$ L=\frac12\lVert\vw\rVert^2-\sum_{k=1}^{n}\lambda_k\bigl(b_k(w_0+\vw^t\vx_k)-1\bigr) $$
条件は「$\ge0$」の向き（$b_k(w_0+\vw^t\vx_k)-1\ge0$）なので、「$\le0$」の形に直すとマイナスが付く。そのため和の前がマイナスになる。
**KKT 条件**（解 $\vw,w_0$ が存在するための必要十分条件）：
$$ \begin{aligned}&\frac{\partial L}{\partial\vw}=\mathbf{0},\quad \frac{\partial L}{\partial w_0}=0,\quad \lambda_k\ge0,\\&b_k(w_0+\vw^t\vx_k)-1\ge0,\\&\lambda_k\bigl(b_k(w_0+\vw^t\vx_k)-1\bigr)=0\end{aligned} $$

## 双対問題：λ だけの問題にする
KKT 条件の最初の2つを計算すると
$$ \begin{aligned}\frac{\partial L}{\partial\vw}=\mathbf{0}\ &\Rightarrow\ \vw=\sum_{k=1}^{n}\lambda_kb_k\vx_k\\\frac{\partial L}{\partial w_0}=0\ &\Rightarrow\ \sum_{k=1}^{n}\lambda_kb_k=0\end{aligned} $$
1つ目で $\vw$ が「学習パターンの足し算」になった（第2回の $\vw=\sum\alpha_kb_k\vx_k$ とそっくり）。これを $L$ に代入すると、$\vw$ と $w_0$ が消えて $\lambda$ だけの式になる。
$$ \begin{aligned}L(\vlam)&=\sum_{k=1}^{n}\lambda_k-\frac12\lVert\vw\rVert^2\\&=\sum_{k=1}^{n}\lambda_k-\frac12\sum_{i=1}^{n}\sum_{j=1}^{n}\lambda_i\lambda_jb_ib_j\,\vx_i^t\vx_j\end{aligned} $$
@fold 代入の計算（自分でやってから開く。ヒント：$L$ を3つの和に分ける）
@steps
$L=\frac12\lVert\vw\rVert^2-\sum_k\lambda_kb_k\vw^t\vx_k$ $-\,w_0\sum_k\lambda_kb_k+\sum_k\lambda_k$ :: かっこを外して、和を3つに分けただけ
2つ目の和 $=\vw^t\sum_k\lambda_kb_k\vx_k=\vw^t\vw=\lVert\vw\rVert^2$ :: $\vw$ はどの $k$ にも共通なので外に出せる。残りは $\vw$ そのもの
3つ目の和は $\sum_k\lambda_kb_k=0$ なので消える :: $\partial L/\partial w_0=0$ の結果
$L=\frac12\lVert\vw\rVert^2-\lVert\vw\rVert^2+\sum_k\lambda_k$ $=\sum_k\lambda_k-\frac12\lVert\vw\rVert^2$ :: 足し引きしただけ
$\lVert\vw\rVert^2=(\sum_i\lambda_ib_i\vx_i)^t(\sum_j\lambda_jb_j\vx_j)$ $=\sum_i\sum_j\lambda_i\lambda_jb_ib_j\vx_i^t\vx_j$ ∎ :: 和どうしの内積は、全部の組の内積の和
@end
@end
= #+SVM の双対問題
= 最大化：$L(\vlam)=\vlam^t\mathbf{1}_n-\frac12\vlam^t\mathbf{H}\vlam$
= 条件：$\vlam^t\vb=0,\quad \vlam\ge0$
= $\mathbf{H}$ の要素 $h_{ij}=b_ib_j\,\vx_i^t\vx_j$、$\mathbf{1}_n=(1,\dots,1)^t$
| | 主問題（元の問題） | 双対問題 |
| 変数 | $\vw,\ w_0$ | $\vlam=(\lambda_1,\dots,\lambda_n)$ |
| 目的 | $\frac12\lVert\vw\rVert^2$ を最小化 | $L(\vlam)$ を**最大化** |
| 条件 | 不等式が $n$ 本 | $\vlam^t\vb=0$ と $\vlam\ge0$ だけ |
| データの出方 | $\vx_k$ そのもの | 内積 $\vx_i^t\vx_j$ だけ |
@box why なぜ双対問題にする？
1つは、**条件が簡単に書ける**から（$\lambda\ge0$ と等式1本だけ）。もう1つは、データが**内積 $\vx_i^t\vx_j$ の形でしか出てこない**から。この内積を別の関数に取り替えると、境界を曲げられる（第7回のカーネル法）。
@end

## サポートベクトル：境界を決めているのは一部の点だけ
双対問題の解を $\vlam^*=(\lambda_1^*,\dots,\lambda_n^*)$（5.38）とすると、重みは $\vw^*=\sum_k\lambda_k^*b_k\vx_k$（5.39）。KKT 条件の $\lambda_k(b_k(\cdots)-1)=0$ から、各パターンはどちらかになる（5.40、5.41）。
| $\lambda_k^*$ | $b_k(w_0^*+\vw^{*t}\vx_k)-1$ | 意味 |
| $>0$ | $=0$ | マージンの端の線の上にいる ＝ **サポートベクトル** |
| $=0$ | $>0$ | 外側にいる。$\vw^*$ に効かない |
**サポートベクトル**（＝$\lambda_k^*>0$ の学習パターン）は、重みの決定に寄与し、決定境界に最も近い。それ以外の点を消しても、答えは変わらない。
= #+サポートベクトルと w₀
= $\vw^*=\sum_k\lambda_k^*b_k\vx_k$（足すのは $\lambda_k^*>0$ の点だけ）
= $w_0=b_s-\vw^{*t}\vx_s$（$\vx_s$ はサポートベクトル）
$w_0$ の式は、サポートベクトルでは $b_s(w_0+\vw^t\vx_s)=1$、両辺に $b_s$ を掛けると $b_s^2=1$ なので $w_0+\vw^t\vx_s=b_s$、から出る。
第2回のパーセプトロンも $\vw=\sum\alpha_kb_k\vx_k$ だった（係数が0でない点＝寄与ベクトル）。SVM ではそれが $\lambda$ に変わり、0 でない点がサポートベクトル。違うのは、SVM の答えは**順序に関係なく1つに決まる**こと。

## SVM の特長（教科書 p.83）
1. 汎化能力が高い ← マージン最大化
2. 複雑な決定境界が表現できる ← カーネルの利用（第7回）
3. 大域的最適解（＝全体で一番いい解）への収束が保証される ← 凸二次計画問題なので谷が1つ
4. 解が一意に決定される ← 同上。パーセプトロン（順序で変わる）との大きな違い
@box exam 試験で取る（第5回のまとめ）
1. 汎化能力 ＝ 学習時に利用していない未知のパターンを識別する能力
2. SVM はマージンを最大化して汎化能力の向上を目指す
3. 線形 SVM（線形分離できる場合）は凸二次計画問題として表現でき、ラグランジュの未定乗数法で解く。より簡単に解ける双対問題が得られる
4. 重みベクトルに寄与する学習データをサポートベクトルと呼ぶ
@end

$\lVert\vw\rVert=\sqrt{9+16}=5$。$g(3,4)=9+16-5=20$ → 距離 $20/5=4$。
マージン $R=2/\lVert\vw\rVert=2/5=0.4$。
@end
