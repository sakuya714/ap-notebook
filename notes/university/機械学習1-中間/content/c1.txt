## ベクトル：点を数字の組で表す
**特徴ベクトル**（＝パターンから取り出した $d$ 個の数字の組）を $\vx=(x_1,x_2,\dots,x_d)^t$ と書く。右上の $t$ は**転置**（＝縦と横を入れ替える記号）で、本当は縦に並んだベクトルを横書きするために付けている。
例えば「飛行機の写真 → (胴体の長さ, 翼の幅)＝(2, 3)」のように、パターン1個が $d$ 次元空間の点1個になる。この空間を**特徴空間**（＝特徴ベクトルが住む $d$ 次元の空間）と呼ぶ。

## 内積：向きがどれだけそろっているか
$$ \vw^t\vx = w_1x_1+w_2x_2+\cdots+w_dx_d $$
成分どうしを掛けて足すだけ。例：$(1,2)$ と $(3,1)$ の内積は $1\cdot3+2\cdot1=5$。
図で言うと $\vw^t\vx=\lVert\vw\rVert\lVert\vx\rVert\cos\theta$（$\theta$ は2本の矢印のなす角）。だから同じ向きなら正、直角なら 0、逆向きなら負になる。
@box why なぜ内積がそんなに大事？
線形識別関数（第1回）・パーセプトロン（第2回）・SVM（第5回）・カーネル（第7回）は、全部「内積を計算して符号や大きさを見る」形をしている。内積が分かれば、この科目の計算の半分は終わり。
@end

## ノルム（長さ）と距離
$$ \lVert\vx\rVert=\sqrt{\vx^t\vx},\qquad D(\vx,\vy)=\lVert\vx-\vy\rVert $$
ノルム（＝ベクトルの長さ）は自分自身との内積のルート。距離は差のベクトルの長さ。例：$(2,3)$ と $(1,3)$ の距離は $\sqrt{1^2+0^2}=1$、$(2,3)$ と $(4,4)$ は $\sqrt{2^2+1^2}=\sqrt5$。冒頭の答えは「$(1,3)$ の方が近い」。
距離の2乗は、内積で展開できる（第1回で使う）。
$$ \lVert\vx-\vp\rVert^2=\lVert\vx\rVert^2-2\vp^t\vx+\lVert\vp\rVert^2 $$
$(a-b)^2=a^2-2ab+b^2$ のベクトル版。

## 直線（超平面）と法線ベクトル
$$ g(\vx)=w_0+\vw^t\vx=0 $$
2次元なら $w_0+w_1x_1+w_2x_2=0$ で直線。3次元なら平面、それ以上は**超平面**（＝ $d$ 次元空間を2つに分ける「平らな仕切り」）。$w_0$ を**バイアス**（＝仕切りの位置をずらす定数）と呼ぶ。
直線の上の2点 $\vx_a,\vx_b$ では $g$ が両方 0 なので、引くと $\vw^t(\vx_a-\vx_b)=0$。つまり $\vw$ は直線の向きと内積 0 ＝ **直線に垂直**。この $\vw$ を**法線ベクトル**（＝境界に垂直な矢印）と呼ぶ。$g(\vx)>0$ なら $\vw$ が指す側、$g(\vx)<0$ なら反対側にいる。
@fold 点と直線の距離 $\lvert g(\vx)\rvert/\lVert\vw\rVert$ を導く（第5回で使う。ヒント：$\vx$ から $\vw$ の向きにまっすぐ下ろす。自分でやってから開く）
@steps
$\vx$ から境界に下ろした垂線の足を $\vx_p$、距離を $r$ として $\vx=\vx_p+r\,\vw/\lVert\vw\rVert$ :: 垂線は $\vw$ と平行。「$\vw$ の向きに長さ $r$ 進む」を式にしただけ（$\vx$ が $\vw$ 側にいるとき）
両辺を $g$ に入れて $g(\vx)=(w_0+\vw^t\vx_p)+r\,\vw^t\vw/\lVert\vw\rVert$ $=r\lVert\vw\rVert$ :: $\vx_p$ は境界の上なので $w_0+\vw^t\vx_p=0$。$\vw^t\vw=\lVert\vw\rVert^2$
$r=g(\vx)/\lVert\vw\rVert$。反対側なら符号が逆なので $r=\lvert g(\vx)\rvert/\lVert\vw\rVert$ ∎ :: 距離は正の量なので絶対値でまとめる
@end
@end
例：$g(\vx)=3x_1+4x_2-5$、点 $(3,4)$ → $g=9+16-5=20$、$\lVert\vw\rVert=\sqrt{3^2+4^2}=5$ → 距離 $20/5=4$。

## ベクトルで微分する
| 関数 | $\vw$ で微分すると | 1次元で言うと |
| $\vw^t\vx$ | $\vx$ | $wx$ を $w$ で微分して $x$ |
| $\frac12\lVert\vw\rVert^2$ | $\vw$ | $\frac12w^2$ を微分して $w$ |
1次元の公式が、そのままベクトルに伸びるだけ。二乗誤差（第3回）と SVM（第5回）で、この2つしか使わない。
**勾配** $\nabla f=\left(\dfrac{\partial f}{\partial x},\dfrac{\partial f}{\partial y}\right)$（＝各方向の傾きを並べたベクトル）は、$f$ が一番増える向きを指し、等高線に直交する。逆向きに少しずつ進めば谷底に近づく（第3回の最急降下法）。

## 確率：事前確率・条件付き確率・事後確率
| 記号 | 名前 | 意味 |
| $P(\omega_i)$ | 事前確率 | データを見る前の、クラス $\omega_i$ の割合 |
| $p(\vx\mid\omega_i)$ | クラス条件付き確率密度 | クラス $\omega_i$ の中で、$\vx$ がどれくらい出やすいか |
| $P(\omega_i\mid\vx)$ | 事後確率 | $\vx$ を見たあとで、それが $\omega_i$ である確率 |
| $p(\vx)$ | 確率密度 | クラスを問わず $\vx$ が出る確率 |
$$ P(\omega_i\mid\vx)=\frac{p(\vx\mid\omega_i)P(\omega_i)}{p(\vx)} $$
これが**ベイズの定理**。「原因（クラス）→ 結果（$\vx$）」の確率から、「結果 → 原因」の確率を出す道具。第3回のベイズ識別関数でそのまま使う。

## max と ⇒ の読み方
$$ \max_{i=1,\dots,c}\{g_i(\vx)\}=g_k(\vx)\;\Longrightarrow\;\vx\in\omega_k $$
「$c$ 個の $g_i$ の中で一番大きいのが $g_k$ なら、$\vx$ をクラス $\omega_k$ に決める」と読む。$\in$ は「〜に属する」。$\omega$（オメガ）はクラスの名前。
@check
内積 $(1,2)^t(3,1)$ と距離 $\lVert(2,3)-(4,4)\rVert$ を10秒で出せる（5 と $\sqrt5$）
$w_0+\vw^t\vx=0$ の $\vw$ が境界に垂直な理由を言える
$\partial(\vw^t\vx)/\partial\vw=\vx$ と $\partial(\frac12\lVert\vw\rVert^2)/\partial\vw=\vw$ を言える
事前確率・条件付き確率密度・事後確率の違いを言える
@end

## 機械学習・パターン認識・識別
| 用語 | 意味 |
| 機械学習 | データからルール（識別のしかた）を自動で学ぶこと。人が経験でルールを書くのは**ルールベース**／**ヒューリスティック**、人が手で設計したものは hand-crafted と呼ぶ |
| 教師あり学習 | 正解ラベル付きのデータで学ぶ（この講義はこれ）。ラベル無しは教師なし学習（クラスタリング・次元削減）、報酬を最大にする行動を学ぶのは強化学習 |
| 深層学習 | 機械学習の技術の1つ（最近の主流）。人工知能 ⊃ 機械学習 ⊃ 深層学習 の入れ子になっている |
| パターン認識 | 画像・音声・文書などを入力にして、それが何を意味するかを認識すること。今は機械学習にほぼ含まれる |
| パターン | 外から観測される信号・データの集合。クラスを決められる情報を持っている必要がある |
| クラス | 同じ性質のものが属する部類（カテゴリ・パターンクラスとも）。記号 $\omega_1,\omega_2,\dots$ を割り当てる |
| 識別 | パターンから、それが属するクラスを得ること |
この講義で扱うのは、正解ラベル付きのデータから識別のしかたを学ぶ教師あり学習。

## 識別の流れ：前処理部 → 特徴抽出部 → 識別部
| 部 | やること |
| 前処理部 | ノイズ除去・正規化（大きさや明るさをそろえる） |
| 特徴抽出部 | 識別に有効な「特徴」を取り出して特徴ベクトルにする。何が有効かは入力の種類（画像・音声…）しだいなので、中身はデータごとに違う |
| 識別部 | 特徴ベクトルに演算をして、どのクラスに属するかを判定する |
識別部の設計 ＝ 特徴空間をクラスごとに**塗り分ける** ＝ クラスの境界（**決定境界**）を決めること。塗り分け方を決めることを**学習**（＝識別部のパラメータを決めること）と呼ぶ。
学習に使う正解付きのデータを**学習パターン**、性能を測るための別のデータを**テストパターン**（本番で来る正体不明のものは**未知パターン**）と呼ぶ。
@box exam 試験で取る
去年は「特徴抽出部の説明として正しいもの」を選ぶ問題が出た。正解側は「識別に有効な特徴を抽出する」「入力データの特性に応じて処理内容が異なる」。ノイズ除去・正規化は**前処理部**、クラスの判定は**識別部**なので、入れ替えに注意。
@end

## 最近傍決定則：一番近い見本と同じクラスにする
各クラスの見本として覚えておく点を**プロトタイプ**と呼ぶ。学習パターンを全部プロトタイプとして覚えるのが**全数記憶方式**。
$$ \vp_k\in\theta_k,\quad \theta_k\in\{\omega_1,\dots,\omega_c\}\quad(k=1,\dots,m) $$
$$ \min_{k=1,\dots,m}\{D(\vx,\vp_k)\}=D(\vx,\vp_j)\;\Longrightarrow\;\vx\in\theta_j $$
$m$ 個のプロトタイプのうち $\vx$ に一番近いのが $\vp_j$ なら、$\vp_j$ のクラス $\theta_j$ に決める。
| 記号 | 意味 |
| $\vp_k$ | $k$ 番目のプロトタイプ（見本の点） |
| $\theta_k$ | プロトタイプ $\vp_k$ が属するクラス（$\omega_1\sim\omega_c$ のどれか。同じクラスの見本が何個あってもいい） |
| $m$ ／ $c$ | プロトタイプの数 ／ クラスの数 |
| $D(\vx,\vp_k)$ | $\vx$ と $\vp_k$ の距離 |
**弱点**：学習パターンに過度に適合してしまう。ラベルを間違えた1点や外れた1点がそのまま境界を作り、その近くの未知パターンを誤識別する。全部の見本と距離を計算するので、見本が多いと重い。
**対策（k 最近傍法）**：近い順に $k$ 個のプロトタイプを見て、一番多いクラスにする（多数決）。1個の誤りに引っぱられにくくなり、決定境界もなめらかになる。

## 例題：見本がクラスに1個ずつ
$\vp_1=(1,3)\in\omega_1$、$\vp_2=(4,4)\in\omega_2$、$\vp_3=(3,1)\in\omega_3$ のとき、$\vx=(2,3)$ はどのクラス？
距離の2乗：$D^2=(2-1)^2+0^2=1$、$(2-4)^2+(3-4)^2=5$、$(2-3)^2+(3-1)^2=5$。一番小さいのは $\vp_1$ → $\vx\in\omega_1$。
@fig nn_boundary | 見本が3個の最近傍決定則 | 境界は、見本どうしの垂直二等分線（＝2点から同じ距離の点の集まり）をつないだもの。つまり**直線**でできている。破線は x から各見本までの距離
見本がクラスに1個ずつなら、境界は直線になる。ということは、最近傍は「直線の式」で書き直せるはず。

## 線形識別関数：最近傍を内積で計算し直す
$$ g(\vx)=w_0+\vw^t\vx=w_0+\sum_{j=1}^{d}w_jx_j $$
**線形識別関数**（＝特徴の重み付き和＋定数）。$\vw=(w_1,\dots,w_d)^t$ を**重み係数**、$w_0$ を**バイアス**と呼ぶ。
見本が1個ずつの最近傍を、距離の展開（{{00}}）で書き直す。
$$ D(\vx,\vp_i)^2=\lVert\vx\rVert^2-2\vp_i^t\vx+\lVert\vp_i\rVert^2 $$
$\lVert\vx\rVert^2$ はどのクラスと比べるときも同じ値なので、大小の比較には効かない。残りに $-\frac12$ を掛けると「距離が最小」が「次の値が最大」に変わる。
= #+最近傍 ＝ 線形識別関数（見本がクラスに1個）
= $g_i(\vx)=\vp_i^t\vx-\frac12\lVert\vp_i\rVert^2\quad(i=1,\dots,c)$
= $\max_i\{g_i(\vx)\}=g_k(\vx)\ \Rightarrow\ \vx\in\omega_k$
= 重み $\vw_i=\vp_i$、バイアス $w_{i0}=-\frac12\lVert\vp_i\rVert^2$
例題で検算：$g_1=(2+9)-5=6$、$g_2=(8+12)-16=4$、$g_3=(6+3)-5=4$ → 最大は $g_1$ で $\omega_1$。$\lVert\vx\rVert^2-2g_i=13-12=1,\ 13-8=5,\ 13-8=5$ で、距離の2乗とぴったり一致 ✓。
@box why なぜ $\lVert\vx\rVert^2$ を捨てていい？
全員の点数から同じ額を引いても順位は変わらないのと同じ。比べたいのは「どのクラスが一番か」だけなので、全クラス共通の項は消してよい。第3回のベイズ識別関数でも $p(\vx)$ を同じ理由で捨てる。
@end
**決定境界**は、識別関数の値が等しくなる所（$g_i(\vx)=g_j(\vx)$）。見本との距離を全部計算するより、内積1回で済むので効率がいい。
ただし、まだ「見本 $\vp_i$ を人が決めている」。どこに置けば一番よく分けられるのかは分からない。

@quiz $\vp_1=(0,0)\in\omega_1$、$\vp_2=(2,2)\in\omega_2$ のとき、$g_1,g_2$ を書いて $\vx=(1.5,1)$ を識別し、決定境界の式を求めよ
$g_1=0$（$\vp_1=\mathbf{0}$ なので）、$g_2=2x_1+2x_2-\frac12\cdot8=2x_1+2x_2-4$。
$\vx=(1.5,1)$：$g_1=0$、$g_2=3+2-4=1$ → $g_2$ が大きいので $\omega_2$。距離で検算：$D^2=3.25$ と $1.25$ → $\vp_2$ が近い ✓。
境界は $g_1=g_2$ → $x_1+x_2=2$（$(0,0)$ と $(2,2)$ の垂直二等分線）。
@end
@check
識別の流れ（前処理部・特徴抽出部・識別部）と各部の役目を言える
最近傍決定則の弱点（過度に適合）と、k 最近傍法での対策を言える
$D^2$ を展開して $g_i(\vx)=\vp_i^t\vx-\frac12\lVert\vp_i\rVert^2$ を導ける
決定境界 ＝ 識別関数の値が等しくなる所、と言える
@end
だから次は：見本を人が置くのをやめて、**重み $\vw$ そのものをデータから直接決める**（{{02}} パーセプトロン）。
