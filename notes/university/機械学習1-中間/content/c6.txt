## 手計算の型（毎回この4ステップ）
@steps 双対問題を手で解く
条件 $\sum_k\lambda_kb_k=0$ に $b_k$ を代入する :: $\lambda$ の数を減らす（2点なら $\lambda_1=\lambda_2$）
$\vw=\sum_k\lambda_kb_k\vx_k$ を $\lambda$ で書く :: $\lVert\vw\rVert^2$ が $\lambda$ の式になる
$L(\vlam)=\sum_k\lambda_k-\frac12\lVert\vw\rVert^2$ を作って、微分 $=0$ :: 上に凸の2次関数なので、頂点が最大
$w_0=b_s-\vw^t\vx_s$（$\vx_s$ はサポートベクトル）:: サポートベクトルでは $g(\vx_s)=b_s$ だから
@end

## 例題1：2点
$\vx_1=(1,1)^t,\ b_1=1$ と $\vx_2=(-1,-1)^t,\ b_2=-1$。
1. 条件に代入：$\lambda_1b_1+\lambda_2b_2=\lambda_1-\lambda_2=0$ → $\lambda_1=\lambda_2$。また $\lambda_1\ge0,\ \lambda_2\ge0$
2. 重み：$\vw=\lambda_1\binom{1}{1}-\lambda_2\binom{-1}{-1}=\binom{\lambda_1+\lambda_2}{\lambda_1+\lambda_2}$
3. 目的関数：$L=\lambda_1+\lambda_2-\frac12\{(\lambda_1+\lambda_2)^2+(\lambda_1+\lambda_2)^2\}$ $=2\lambda_1-4\lambda_1^2$。$\dfrac{dL}{d\lambda_1}=2-8\lambda_1=0$ → $\lambda_1=\lambda_2=\frac14$
4. $\vw=(\frac12,\frac12)$。$\vx_1$ はサポートベクトルなので $g(\vx_1)=b_1=1$：$w_0+\frac12+\frac12=1$ → $w_0=0$
答え：$g(\vx)=\frac12x_1+\frac12x_2$。検算：$g(\vx_2)=-1=b_2$ ✓。マージン $R=2/\lVert\vw\rVert=2/(1/\sqrt2)=2\sqrt2\approx2.83$ で、2点の距離 $\lVert\vx_1-\vx_2\rVert=2\sqrt2$ とぴったり同じ ✓（2点しかないので、2点のちょうど真ん中に垂直に境界が立つ）。

## 例題2：3点（遠い点は効かない）
$\vx_3=(2,1)^t,\ b_3=1$ を足す。
1. 条件：$\lambda_1-\lambda_2+\lambda_3=0$ → $\lambda_1=\lambda_2-\lambda_3$。$\lambda_1\ge0$ なので $\lambda_2\ge\lambda_3\ge0$
2. 重み：$\vw=\lambda_1\binom11-\lambda_2\binom{-1}{-1}+\lambda_3\binom21$ $=\binom{\lambda_1+\lambda_2+2\lambda_3}{\lambda_1+\lambda_2+\lambda_3}=\binom{2\lambda_2+\lambda_3}{2\lambda_2}$（最後に $\lambda_1=\lambda_2-\lambda_3$ を代入）
3. $\lambda_1+\lambda_2+\lambda_3=2\lambda_2$ なので
$$ \begin{aligned}L&=2\lambda_2-\frac12\{(2\lambda_2+\lambda_3)^2+(2\lambda_2)^2\}\\&=2\lambda_2-4\lambda_2^2-2\lambda_2\lambda_3-\frac12\lambda_3^2\end{aligned} $$
$\lambda_2$ を固定して考えると、$\lambda_3$ を含む部分 $-2\lambda_2\lambda_3-\frac12\lambda_3^2$ は $\lambda_3\ge0$ の範囲で 0 以下。だから $\lambda_3=0$ のとき最大。すると $L=2\lambda_2-4\lambda_2^2$ で、例題1と同じく $\lambda_2=\frac14$。
答え：$\lambda_1=\lambda_2=\frac14,\ \lambda_3=0$。以下は2点のときと同じで $g(\vx)=\frac12x_1+\frac12x_2$。
$\vx_3$ を確かめると $b_3g(\vx_3)=1+\frac12=1.5>1$：マージンの外にいるので $\lambda_3=0$（第5回の表の下の行）✓。{{05}} の図がまさにこの3点。境界を決めているのはサポートベクトル2つだけで、遠い点は何個増えても答えを変えない。
@box exam 試験で取る
去年の問20は、この2点の例と同じ形の手計算（点の座標だけ違う）。手順の4ステップと、「$w_0$ はサポートベクトルの $g(\vx_s)=b_s$ から」を体で覚える。
下の確認問題は、点を半分の $(\pm\frac12,\pm\frac12)$ にした版。
@end
@quiz $\vx_1=(\frac12,\frac12)^t,\ b_1=1$、$\vx_2=(-\frac12,-\frac12)^t,\ b_2=-1$ で SVM を手計算し、$\lambda,\ \vw,\ w_0$、マージン $R$ を求めよ
1. $\lambda_1-\lambda_2=0$ → $\lambda_1=\lambda_2$
2. $\vw=\lambda_1(\frac12,\frac12)+\lambda_2(\frac12,\frac12)=(\lambda_1,\lambda_1)$
3. $L=2\lambda_1-\frac12(\lambda_1^2+\lambda_1^2)=2\lambda_1-\lambda_1^2$、$\dfrac{dL}{d\lambda_1}=2-2\lambda_1=0$ → $\lambda_1=\lambda_2=1$
4. $\vw=(1,1)$、$g(\vx_1)=w_0+\frac12+\frac12=1$ → $w_0=0$。$g(\vx)=x_1+x_2$
$R=2/\lVert\vw\rVert=2/\sqrt2=\sqrt2$（2点の距離 $\sqrt2$ と一致 ✓）。点を半分にすると $\lambda$ は4倍、$\vw$ は2倍、$R$ は半分になる。
@end

## 線形分離できないとき：スラック変数 ξ
ハードマージンの条件 $b_k(w_0+\vw^t\vx_k)\ge1$ は、1点でも反対側に入り込むと満たせない。そこで点ごとに「はみ出してもいい量」$\xi_k\ge0$ を用意する。
$$ b_k(w_0+\vw^t\vx_k)\ \ge\ 1-\xi_k\qquad(\xi_k\ge0) $$
$\xi_k$ を**スラック変数**（＝条件をゆるめる「遊び」の量）と呼ぶ。条件を満たす一番小さい値は $\xi_k=\max(0,\ 1-b_kg(\vx_k))$。
| $\xi_k$ | どこにいる？ |
| $0$ | マージンの外（ルールどおり） |
| $0<\xi_k\le1$ | マージンの内側に入ったが、境界の正しい側 |
| $\xi_k>1$ | 境界の反対側 ＝ 誤識別 |
@fig soft_margin | ソフトマージンとスラック変数（g＝x₁−x₂） | A（ω₁）は g＝0.4：内側に入ったが正しい側 → ξ＝1−0.4＝0.6。B（ω₁）は g＝−0.7：境界を越えて反対側 → ξ＝1−(−0.7)＝1.7（誤識別）

## ソフトマージンSVM：はみ出しに罰金
$\xi_k$ を大きくすれば、どんな $\vw$ でも条件を満たせてしまう（マージン $R$ もいくらでも大きくできる）。それで良いのか？ → 良くない。はみ出した量にも罰金を課して、一緒に最小化する。
= #+ソフトマージンSVM
= 条件：$b_k(w_0+\vw^t\vx_k)\ge1-\xi_k,\quad \xi_k\ge0$
= 目的：$\min\ L=\frac12\lVert\vw\rVert^2+c_{pe}\sum_{k=1}^{n}\xi_k$
$c_{pe}$ は**誤識別に対する重み係数**（＝はみ出し1単位あたりの罰金の重さ）。学習の前に人が決める値で、こういう値を**ハイパーパラメータ**と呼ぶ。
| $c_{pe}$ | 罰金 | 結果 |
| 大きい | 重い | はみ出しを許さない → ハードマージンに近い（マージンは狭め） |
| 小さい | 軽い | はみ出しに寛容 → マージンは広め |
これまでの（はみ出しを許さない）ものを**ハードマージンSVM**、ξ を入れたものを**ソフトマージンSVM**と呼ぶ。

## SVM を使う上での留意点
1. そのままでは3クラス以上の識別ができない（2クラス用を組み合わせる）
2. 凸二次計画法を解くための計算量に注意が必要（学習パターン数 $n$ が増えると、$n\times n$ の $\mathbf{H}$ を扱うので重い）
3. 重み係数 $c_{pe}$ はあらかじめ設定する必要がある（ハイパーパラメータ）
4. クラスによって学習パターンの数に大きな偏りがある場合に注意が必要（クラスごとに $c_{pe}$ を変えるなど）
@box exam 試験で取る（第6回のまとめ）
1. SVM はラグランジュの「未定乗数法」で解く。「双対問題」にすると原問題より「解きやすい形」になる
2. サポートベクトル：決定境界の決定に「寄与する」学習パターン。解法の中で「$\lambda>0$」となるものに対応
3. 線形分離できる → 「ハードマージン」SVM ／ できない → 「ソフトマージン」SVM（「スラック変数」と、誤識別に対する「重み係数」を導入）
4. 去年は「$c_{pe}$ は何と呼ばれるか（ハイパーパラメータ）」「留意点として正しいもの」が出た
@end

@quiz $g(\vx)=x_1-x_2$ のソフトマージンSVMで、A $(1.8,1.4)$・$b=+1$、B $(1.5,2.2)$・$b=+1$、C $(0.3,2.0)$・$b=-1$ の $\xi$ を求めよ

@end
