# Notebook Hub

試験範囲の総まとめ（Web版ノート）を1つのサイトにまとめたもの。

**本の形はどのノートも1つ。違うのは中身だけ。** 整理型か理解型かは「本文をどう書くか」の違いで、サイトの仕組み・見た目・使える部品は全部同じ。

## 置き場所のルール（いちばん大事）

| 場所 | 中身 | ここに書いてはいけないもの |
|---|---|---|
| `theme/` | 見た目と動き（色・文字・レイアウト・サイドバー・検索・部品のデザイン） | 科目の言葉（応用・基本情報・パーセプトロン…）、ノートごとの例外 |
| `engine/` | 本文 → HTML の変換、図の部品、ビルド | 同上 |
| `notes/<フォルダ>/<ノート>/` | そのノートの中身だけ（本文・図・ノート固有の言葉） | CSS・HTML の骨組み・色の値 |

迷ったら「2冊目のノートでもそのまま使うか？」で判断する。使うなら theme/ か engine/、そのノートだけなら notes/。

## チェック（ビルドのたびに自動）

`python3 hub.py build` の最初に `engine/check.py` が全ノートを調べ、**エラーが1つでもあればビルドを止める**（`python3 hub.py check` で単独でも走る）。

- 書き間違い：知らない `@記法`、`@xxx` と `@end` の数の食い違い、`@box` の種類、存在しない章への `{{リンク}}`・`@pair`・路線図の駅、figs.py に無い `@fig`、note.json の不備（注意：`**` や `$` の閉じ忘れ、知らない note.json の項目）
- 公開してはいけない情報：メール・電話番号・学籍番号の形・APIキー・Mac のパス、それと `.private-words` に書いた言葉（本名・大学名・仕事の案件名など）。`.private-words` 自体は公開しない（.gitignore）

このサイトは GitHub（`sakuya714/notebook-hub`）で**公開**している。ノートに個人情報・仕事の情報・教材の丸写し（スライドの画像やPDFをそのまま貼る）を入れない。

## 使い方

```bash
python3 hub.py build                      # チェック → notes/ → docs/（docs/index.html を開けば見られる）
python3 hub.py check                      # チェックだけ
python3 hub.py serve                      # 作り直して http://127.0.0.1:8765 で開く
python3 hub.py new university/統計-期末 理解型   # ノートのひな形（型は 整理型 か 理解型）
python3 hub.py mkdir university/2年後期     # フォルダ
```

## ファイル構成

```
notebook-hub/

├── engine/                     … 製本機（全ノート共通）
│   ├── builder.py              …   notes/ を読んで docs/ に組み立てる
│   ├── markup.py               …   本文の記法 → HTML（記法は下の表）
│   ├── figkit.py               …   図の部品（svg・text・path・arrow_defs・fig）
│   ├── search.py               …   全文検索の索引
│   └── check.py                …   書き間違い・公開NG情報のチェック
├── theme/                      … 本の形（全ノート共通）
│   ├── layout.html             …   全ページの骨組み（上部バー・サイドバー）
│   ├── theme.css               …   色・文字・外枠
│   ├── blocks.css              …   本文の部品の見た目
│   ├── app.js                  …   サイドバー・検索・テーマ・表示切替・○×・チェック
│   ├── math.js                 …   数式（MathJax）の設定
│   └── vendor/mathjax/         …   数式の表示（数式があるページだけ読む）
├── notes/                      … 中身。フォルダ構造＝サイドバーの並び
│   └── learning/応用情報技術者/

│       ├── figs.py             …   図（任意）。def した関数名がそのまま @fig の名前
```

## note.json

```json
{
  "title": "応用情報まとめ",
  "type": "整理型",
  "labels": {"base": "基本情報でやったやつ", "accent": "応用で増えたやつ", "accentShort": "応", "star": "よく出る"},
  "macros": {"vx": "{\\mathbf{x}}"}
}
```

- `type`（必須）：`整理型` か `理解型`。**書き始める前に決めて入れる**。ホームのカードに出るだけで、見た目・使える部品は変わらない（どう書いたかの記録）
- `labels`：`-`（グレー）と `+`（金）が何を意味するか。凡例と「〇〇だけ」ボタンの名前になる（無ければ「ふつう／大事なところ／大事だけ」）
- `macros`：数式のマクロ（`\vx` など）

凡例・表示切替ボタン・数式の読み込みは、**そのノートで実際に使った部品だけ**自動で出る。

## 本文の書き方（content/*.txt）

### 骨組み
| 書き方 | 表示 |
|---|---|
| `@cover` → `eyebrow:` `tag:` `lead:` `title:` → `@end` | 表紙（凡例は自動） |
| `@part p1 \| タイトル \| ひとこと \| 短い名前` | パートの帯（上部バーに短い名前で並ぶ） |
| `@ch 01-1 \| 章タイトル \| サブタイトル` | 章（1枚のシート）。`{{01-1}}` でリンク |
| `@board id \| タイトル \| ひとこと \| 上部バーの名前` | 章以外の区画（地図・巻末など） |
| `@toc` ／ `@formulas` ／ `@pairs` | 章の一覧 ／ 全章の公式 ／ 全ひっかけペア を自動で集めて置く |
| `## 見出し` | 小見出し |

### 用語・暗記（整理型でよく使う）
| 書き方 | 表示 |
|---|---|
| `( ラベル` 〜 `)` | 用語のグループ |
| `- 用語 — 説明` ／ `+ 用語 — 説明` | グレー ／ 金。`-*` `+*` で★ |
| `= #ラベル`（`= #+ラベル` で金枠）→ `= 式` → `= 例）…` | 公式ボックス（`@formulas` に集まる） |
| `> メモ` ／ `! 注意` | ✎ 覚え方 ／ ひっかけ |
| `\| a \| b \|`（`+\|` で金の行） | 表（1行目が見出し） |
| `@pair 区分 \| A \| B \| 見分け方 \| 章` | ひっかけペア（`@pairs` に集まる） |
| `@map` → `flow: A::補足 > +B` → 1行 → `@end` | この章の流れ |
| `@flow A::補足 >[矢印の字] +B \|\| キャプション` | 流れ図 |
| `@stack` ／ `@lad タイトル \| 上 \| 下` ／ `@mx` … `@end` | 積み重ね ／ はしご ／ 2×2 |
| `@stats` → `数字 :: 説明` → `@end` | 数字のタイル |
| `@routes` → `名前 \| ひとこと \| 01-1 駅名, 02-2 駅名` → `@end` | 章をまたぐ路線図 |

### 文章・数式（理解型でよく使う）
| 書き方 | 表示 |
|---|---|
| ふつうの行 | 段落（60字を超える行は1段で広く読ませる） |
| `$式$` ／ `$$ 式 \tag{1.17} $$` | 文中の数式 ／ 1行の数式 |
| `1. 手順` | 番号付きリスト |
| `@box why\|exam\|warn\|goal 見出し` … `@end` | なぜ（緑）／試験で取る（金）／勘違い（珊瑚）／ゴール |
| `@fold 見出し` … `@end` | たたむ（導出など） |
| `@quiz 問題` … `@end` | 確認問題（答えはたたむ） |
| `@ox` → `○ 文 :: 解説` ／ `× 文 :: 解説` → `@end` | ○×（押すと答え） |
| `@check` → 1行ずつ → `@end` | これが言えたら次へ（チェックは端末に保存） |
| `@steps タイトル` → `操作 :: なぜ` → `@end` | 手順 |
| ```` ``` ```` 〜 ```` ``` ```` | コード |
| `@fig 名前 \| タイトル \| キャプション`（`@fig!` で1段まるごと） | figs.py の図 |

`**太字**` ／ `==金色==` ／ `` `コード` `` ／ `{{01-1}}`（章リンク）は文中どこでも使える。`@box` などの中にも同じ記法がそのまま書ける。

### 段組み
用語・公式・表などの短い部品が3つ以上続いた所だけ自動で2段組になる。文章・数式・囲み・たたみは1段で読ませる。ノート側で段組みを指定することはない。
