数学の準備

ベクトル・内積・距離・直線・微分・確率。この先で本当に使う道具だけ

点 \((2,3)\) は、点 \((1,3)\) と点 \((4,4)\) のどっちに近い？ ── このノートの話は全部、この手の「点どうしの近さ・向き」の計算でできている。先に道具をそろえておく。

ゴール
  1. ベクトル・内積・ノルム（長さ）を、2次元の数字で10秒で計算できる
  2. 直線 \(w_0+\vw^t\vx=0\) で、\(\vw\) が境界に垂直な理由と、点と直線の距離の式を言える
  3. ベクトルの微分2つと、ベイズの定理の各記号の意味を言える
ベクトル：点を数字の組で表す

特徴ベクトル（＝パターンから取り出した \(d\) 個の数字の組）を \(\vx=(x_1,x_2,\dots,x_d)^t\) と書く。右上の \(t\) は転置（＝縦と横を入れ替える記号）で、本当は縦に並んだベクトルを横書きするために付けている。

例えば「飛行機の写真 → (胴体の長さ, 翼の幅)＝(2, 3)」のように、パターン1個が \(d\) 次元空間の点1個になる。この空間を特徴空間（＝特徴ベクトルが住む \(d\) 次元の空間）と呼ぶ。

内積：向きがどれだけそろっているか
\[\vw^t\vx = w_1x_1+w_2x_2+\cdots+w_dx_d\]

成分どうしを掛けて足すだけ。例：\((1,2)\) と \((3,1)\) の内積は \(1\cdot3+2\cdot1=5\)。

図で言うと \(\vw^t\vx=\lVert\vw\rVert\lVert\vx\rVert\cos\theta\)（\(\theta\) は2本の矢印のなす角）。だから同じ向きなら正、直角なら 0、逆向きなら負になる。

なぜ内積がそんなに大事？

線形識別関数（第1回）・パーセプトロン（第2回）・SVM（第5回）・カーネル（第7回）は、全部「内積を計算して符号や大きさを見る」形をしている。内積が分かれば、この科目の計算の半分は終わり。

ノルム（長さ）と距離
\[\lVert\vx\rVert=\sqrt{\vx^t\vx},\qquad D(\vx,\vy)=\lVert\vx-\vy\rVert\]

ノルム（＝ベクトルの長さ）は自分自身との内積のルート。距離は差のベクトルの長さ。例：\((2,3)\) と \((1,3)\) の距離は \(\sqrt{1^2+0^2}=1\)、\((2,3)\) と \((4,4)\) は \(\sqrt{2^2+1^2}=\sqrt5\)。冒頭の答えは「\((1,3)\) の方が近い」。

距離の2乗は、内積で展開できる（第1回で使う）。

\[\lVert\vx-\vp\rVert^2=\lVert\vx\rVert^2-2\vp^t\vx+\lVert\vp\rVert^2\]

\((a-b)^2=a^2-2ab+b^2\) のベクトル版。

直線（超平面）と法線ベクトル
\[g(\vx)=w_0+\vw^t\vx=0\]

2次元なら \(w_0+w_1x_1+w_2x_2=0\) で直線。3次元なら平面、それ以上は超平面（＝ \(d\) 次元空間を2つに分ける「平らな仕切り」）。\(w_0\) をバイアス（＝仕切りの位置をずらす定数）と呼ぶ。

直線の上の2点 \(\vx_a,\vx_b\) では \(g\) が両方 0 なので、引くと \(\vw^t(\vx_a-\vx_b)=0\)。つまり \(\vw\) は直線の向きと内積 0 ＝ 直線に垂直。この \(\vw\) を法線ベクトル（＝境界に垂直な矢印）と呼ぶ。\(g(\vx)>0\) なら \(\vw\) が指す側、\(g(\vx)<0\) なら反対側にいる。

点と直線の距離 \(\lvert g(\vx)\rvert/\lVert\vw\rVert\) を導く（第5回で使う。ヒント：\(\vx\) から \(\vw\) の向きにまっすぐ下ろす。自分でやってから開く）
  1. \(\vx\) から境界に下ろした垂線の足を \(\vx_p\)、距離を \(r\) として \(\vx=\vx_p+r\,\vw/\lVert\vw\rVert\)垂線は \(\vw\) と平行。「\(\vw\) の向きに長さ \(r\) 進む」を式にしただけ（\(\vx\) が \(\vw\) 側にいるとき）
  2. 両辺を \(g\) に入れて \(g(\vx)=(w_0+\vw^t\vx_p)+r\,\vw^t\vw/\lVert\vw\rVert\) \(=r\lVert\vw\rVert\)\(\vx_p\) は境界の上なので \(w_0+\vw^t\vx_p=0\)。\(\vw^t\vw=\lVert\vw\rVert^2\)
  3. \(r=g(\vx)/\lVert\vw\rVert\)。反対側なら符号が逆なので \(r=\lvert g(\vx)\rvert/\lVert\vw\rVert\) ∎距離は正の量なので絶対値でまとめる

例：\(g(\vx)=3x_1+4x_2-5\)、点 \((3,4)\) → \(g=9+16-5=20\)、\(\lVert\vw\rVert=\sqrt{3^2+4^2}=5\) → 距離 \(20/5=4\)。

ベクトルで微分する
関数\(\vw\) で微分すると1次元で言うと
\(\vw^t\vx\)\(\vx\)\(wx\) を \(w\) で微分して \(x\)
\(\frac12\lVert\vw\rVert^2\)\(\vw\)\(\frac12w^2\) を微分して \(w\)

1次元の公式が、そのままベクトルに伸びるだけ。二乗誤差（第3回）と SVM（第5回）で、この2つしか使わない。

勾配 \(\nabla f=\left(\dfrac{\partial f}{\partial x},\dfrac{\partial f}{\partial y}\right)\)（＝各方向の傾きを並べたベクトル）は、\(f\) が一番増える向きを指し、等高線に直交する。逆向きに少しずつ進めば谷底に近づく（第3回の最急降下法）。

確率：事前確率・条件付き確率・事後確率
記号名前意味
\(P(\omega_i)\)事前確率データを見る前の、クラス \(\omega_i\) の割合
\(p(\vx\mid\omega_i)\)クラス条件付き確率密度クラス \(\omega_i\) の中で、\(\vx\) がどれくらい出やすいか
\(P(\omega_i\mid\vx)\)事後確率\(\vx\) を見たあとで、それが \(\omega_i\) である確率
\(p(\vx)\)確率密度クラスを問わず \(\vx\) が出る確率
\[P(\omega_i\mid\vx)=\frac{p(\vx\mid\omega_i)P(\omega_i)}{p(\vx)}\]

これがベイズの定理。「原因（クラス）→ 結果（\(\vx\)）」の確率から、「結果 → 原因」の確率を出す道具。第3回のベイズ識別関数でそのまま使う。

max と ⇒ の読み方
\[\max_{i=1,\dots,c}\{g_i(\vx)\}=g_k(\vx)\;\Longrightarrow\;\vx\in\omega_k\]

「\(c\) 個の \(g_i\) の中で一番大きいのが \(g_k\) なら、\(\vx\) をクラス \(\omega_k\) に決める」と読む。\(\in\) は「〜に属する」。\(\omega\)（オメガ）はクラスの名前。

最近傍決定則：一番近い見本と同じクラスにする

各クラスの見本として覚えておく点をプロトタイプと呼ぶ。学習パターンを全部プロトタイプとして覚えるのが全数記憶方式。

\[\vp_k\in\theta_k,\quad \theta_k\in\{\omega_1,\dots,\omega_c\}\quad(k=1,\dots,m)\]
\[\min_{k=1,\dots,m}\{D(\vx,\vp_k)\}=D(\vx,\vp_j)\;\Longrightarrow\;\vx\in\theta_j\]

\(m\) 個のプロトタイプのうち \(\vx\) に一番近いのが \(\vp_j\) なら、\(\vp_j\) のクラス \(\theta_j\) に決める。

記号意味
\(\vp_k\)\(k\) 番目のプロトタイプ（見本の点）
\(\theta_k\)プロトタイプ \(\vp_k\) が属するクラス（\(\omega_1\sim\omega_c\) のどれか。同じクラスの見本が何個あってもいい）
\(m\) ／ \(c\)プロトタイプの数 ／ クラスの数
\(D(\vx,\vp_k)\)\(\vx\) と \(\vp_k\) の距離

弱点：学習パターンに過度に適合してしまう。ラベルを間違えた1点や外れた1点がそのまま境界を作り、その近くの未知パターンを誤識別する。全部の見本と距離を計算するので、見本が多いと重い。

対策（k 最近傍法）：近い順に \(k\) 個のプロトタイプを見て、一番多いクラスにする（多数決）。1個の誤りに引っぱられにくくなり、決定境界もなめらかになる。

例題：見本がクラスに1個ずつ

\(\vp_1=(1,3)\in\omega_1\)、\(\vp_2=(4,4)\in\omega_2\)、\(\vp_3=(3,1)\in\omega_3\) のとき、\(\vx=(2,3)\) はどのクラス？

距離の2乗：\(D^2=(2-1)^2+0^2=1\)、\((2-4)^2+(3-4)^2=5\)、\((2-3)^2+(3-1)^2=5\)。一番小さいのは \(\vp_1\) → \(\vx\in\omega_1\)。

見本が3個の最近傍決定則
境界は、見本どうしの垂直二等分線（＝2点から同じ距離の点の集まり）をつないだもの。つまり直線でできている。破線は x から各見本までの距離

見本がクラスに1個ずつなら、境界は直線になる。ということは、最近傍は「直線の式」で書き直せるはず。

線形識別関数：最近傍を内積で計算し直す
\[g(\vx)=w_0+\vw^t\vx=w_0+\sum_{j=1}^{d}w_jx_j\]

線形識別関数（＝特徴の重み付き和＋定数）。\(\vw=(w_1,\dots,w_d)^t\) を重み係数、\(w_0\) をバイアスと呼ぶ。

見本が1個ずつの最近傍を、距離の展開（→00）で書き直す。

\[D(\vx,\vp_i)^2=\lVert\vx\rVert^2-2\vp_i^t\vx+\lVert\vp_i\rVert^2\]

\(\lVert\vx\rVert^2\) はどのクラスと比べるときも同じ値なので、大小の比較には効かない。残りに \(-\frac12\) を掛けると「距離が最小」が「次の値が最大」に変わる。

最近傍 ＝ 線形識別関数（見本がクラスに1個）
\(g_i(\vx)=\vp_i^t\vx-\frac12\lVert\vp_i\rVert^2\quad(i=1,\dots,c)\) \(\max_i\{g_i(\vx)\}=g_k(\vx)\ \Rightarrow\ \vx\in\omega_k\) 重み \(\vw_i=\vp_i\)、バイアス \(w_{i0}=-\frac12\lVert\vp_i\rVert^2\)

例題で検算：\(g_1=(2+9)-5=6\)、\(g_2=(8+12)-16=4\)、\(g_3=(6+3)-5=4\) → 最大は \(g_1\) で \(\omega_1\)。\(\lVert\vx\rVert^2-2g_i=13-12=1,\ 13-8=5,\ 13-8=5\) で、距離の2乗とぴったり一致 ✓。

なぜ \(\lVert\vx\rVert^2\) を捨てていい？

全員の点数から同じ額を引いても順位は変わらないのと同じ。比べたいのは「どのクラスが一番か」だけなので、全クラス共通の項は消してよい。第3回のベイズ識別関数でも \(p(\vx)\) を同じ理由で捨てる。

決定境界は、識別関数の値が等しくなる所（\(g_i(\vx)=g_j(\vx)\)）。見本との距離を全部計算するより、内積1回で済むので効率がいい。

ただし、まだ「見本 \(\vp_i\) を人が決めている」。どこに置けば一番よく分けられるのかは分からない。

確認\(\vp_1=(0,0)\in\omega_1\)、\(\vp_2=(2,2)\in\omega_2\) のとき、\(g_1,g_2\) を書いて \(\vx=(1.5,1)\) を識別し、決定境界の式を求めよ

\(g_1=0\)（\(\vp_1=\mathbf{0}\) なので）、\(g_2=2x_1+2x_2-\frac12\cdot8=2x_1+2x_2-4\)。

\(\vx=(1.5,1)\)：\(g_1=0\)、\(g_2=3+2-4=1\) → \(g_2\) が大きいので \(\omega_2\)。距離で検算：\(D^2=3.25\) と \(1.25\) → \(\vp_2\) が近い ✓。

境界は \(g_1=g_2\) → \(x_1+x_2=2\)（\((0,0)\) と \((2,2)\) の垂直二等分線）。

パーセプトロン

第2回 ── 間違えたら w を直す

直線（重み \(\vw\)）を、データから自動で決めるには？

この章の流れ
拡張ベクトル先頭に1を足す→2クラスを1本にg＝g₁−g₂→間違えたら足すw′＝w＋ρbx→寄与ベクトルw＝Σαbx→マージン余裕を持たせる
「間違えたパターンを \(\vw\) に足す」だけ。線形分離可能なら、これで必ず止まる。

前の回の弱点：線形識別関数の \(\vw\) は見本 \(\vp_i\) で決まるが、良い見本は誰も教えてくれない → \(\vw\) を直接、データで少しずつ直していく。

2クラスを1本の g にまとめる

学習のゴールは、すべての学習パターン \(\vx\)（クラス \(\omega_i\)）で \(g_i(\vx)>g_j(\vx)\ (j\ne i)\) にすること（1.23）。こうできる \(\vw\) がある＝直線（超平面）1本で全部分けられることを線形分離可能、無いことを線形分離不可能と言う。

\[g(\vx)\overset{\mathrm{def}}{=}g_1(\vx)-g_2(\vx)=(\vw_1-\vw_2)^t\vx=\vw^t\vx\]

\[\begin{aligned}S_W=&\sum_{\vx\in\omega_1}(\vx-\vm_1)(\vx-\vm_1)^t\\&+\sum_{\vx\in\omega_2}(\vx-\vm_2)(\vx-\vm_2)^t\end{aligned}\tag{2.23}\]

クラス内変動行列 \(S_W\)（＝各クラスの平均からのばらつきを合計した行列）。

フィッシャーの方法（2.24）
最大化：\(J(\vw)=\dfrac{\{\vw^t(\vm_1-\vm_2)\}^2}{\vw^tS_W\vw}\) 解の向き：\(\vw=a\cdot S_W^{-1}(\vm_1-\vm_2)\)

分子は「射影したときの平均の差の2乗」（大きいほど離れている）、分母は「射影したときのクラス内のばらつき」（小さいほど集まっている）。\(a\) は長さを決めるだけの定数で、大事なのは向き。向きが決まったら、射影した1次元の軸の上でしきい値を決めれば境界になる。

ポテンシャル関数法：原空間で直接、曲がった境界を作る

電荷のたとえ。\(\omega_1\) の学習パターンを＋の電荷、\(\omega_2\) を−の電荷と思うと、点 \(\vx\) には全部の電荷からの静電ポテンシャル（＝電荷が作る「高さ」。近いほど強い）の合計がかかる。それを識別関数として扱う。

\(K(\vx,\vx_k)\) をポテンシャル関数（＝\(\vx_k\) を中心にした山。\(\vx\) が近いほど大きい）と呼び、ガウス関数（釣鐘型の山）がよく使われる。\(q_k\) はその山の高さと符号。

  2. 学習パターンと教師信号を用意し、誤り計数ベクトルを \(\valpha=\mathbf{0}\) にする(4.10)

  5. 全部正しく識別できたら終了。でなければくり返す双対パーセプトロンとまったく同じ形

汎化能力：未知のデータで正しく分けられるか

汎化能力（＝学習に使っていない未知のパターンを、正しく識別できる能力）。学習パターンを全部正しく分けられても、未知パターンで間違えるなら意味がない。第2回で見たとおり、境界とのあいだに余裕（マージン）がある方が汎化能力を高められると期待できる。

種類使うもの前提

上の2つをまとめて線形サポートベクトルマシンと呼ぶ。

SVM では \(w_0\) をまた外に出す

第2〜4回は拡張ベクトルで \(g(\vx)=\vw^t\vx\) と書いたが、SVM では \(g(\vx)=w_0+\vw^t\vx\) とバイアスを分けて書く。\(\vw\) に \(w_0\) は入っていない。マージンの大きさを決めるのは \(\vw\) だけだから（\(w_0\) は境界を平行にずらすだけ）。

マージンの式：点と境界の距離

パターン \(\vx_k\) と決定境界 \(g(\vx)=0\) の距離は（→00 で導いた式、教科書の式 (1.40)）

\[r_k=\frac{\lvert g(\vx_k)\rvert}{\lVert\vw\rVert}\]

すべての学習パターンが、境界から \(R/2\) 以上離れていてほしい（\(R\) がマージンの幅）。正しく分けられているなら \(\lvert g(\vx_k)\rvert=b_kg(\vx_k)\) なので

\[r_k=\frac{b_k(w_0+\vw^t\vx_k)}{\lVert\vw\rVert}\ \ge\ \frac R2\quad(k=1,\dots,n)\]

ここで、\(w_0\) と \(\vw\) を全部同じ倍率で何倍しても境界 \(g=0\) は変わらない。そこで「境界に一番近いパターンで \(b_kg(\vx_k)\) がちょうど 1 になる」ように倍率をそろえる（5.6）。すると条件はこう書ける。

\[b_k(w_0+\vw^t\vx_k)\ \ge\ 1\quad(k=1,\dots,n)\]

一番近いパターンでは \(r_k=1/\lVert\vw\rVert\)（5.7）なので、マージンの幅は \(R=2/\lVert\vw\rVert\)（5.8）。

ハードマージンSVM（線形分離できる場合）
条件：\(b_k(w_0+\vw^t\vx_k)\ge1\quad(k=1,\dots,n)\) 目的：\(\min_{\vw}\ \frac12\lVert\vw\rVert^2\) （マージン \(R=\dfrac{2}{\lVert\vw\rVert}\) を最大にするのと同じ）
記号意味
\(b_k\)教師信号（\(+1\) か \(-1\)）
\(\vx_k\)特徴ベクトル（拡張しない）
\(R\)マージン（境界の両側の余裕を合わせた幅）
\(r_k\)パターン \(\vx_k\) と境界の距離
なぜ「\(R\) を最大化」が「\(\frac12\lVert\vw\rVert^2\) を最小化」になる？

\(R=2/\lVert\vw\rVert\) を大きくする ⇔ \(\lVert\vw\rVert\) を小さくする ⇔ \(\lVert\vw\rVert^2\) を小さくする（ルートが消えて微分しやすい）。\(\frac12\) は、微分すると \(\vw\) だけが残ってきれいになるため（→00）。

試験で取る

「SVM は \(\frac12\lVert\vw\rVert^2\) を最大化する」はひっかけ（去年の選択問題）。正しくは最小化。

マージンとサポートベクトル（第6回の手計算の3点）
答えは g＝½x₁＋½x₂。x₁ と x₂ がマージンの端 g＝±1 の線に乗っている（サポートベクトル）。x₃ は外側にいて、境界の位置に効かない。青緑の破線が x₁ と境界の距離 r＝1/‖w‖＝√2

これは条件付き極値問題（＝条件を守りながら最小を探す問題）。しかも目的が2次式・条件が1次式なので凸二次計画問題（＝谷が1つしかない、解きやすい最適化問題）になる。解き方がラグランジュの未定乗数法。

ラグランジュの未定乗数法：条件付きで最小を探す道具

いったん SVM を離れて、一般の形で考える。\(f(x,y)\) を最小化したい。ただし条件 \(g(x,y)\le0\) を守る。（ここの \(g\) は識別関数ではなく、制約を表す関数。スライドの記号のまま）

勾配 \(\nabla f=\left(\dfrac{\partial f}{\partial x},\dfrac{\partial f}{\partial y}\right)\)（ナブラ）は、\(f\) が一番増える向きを向き、等高線に直交する。

最小点が条件の領域の中か外か
左：f の最小点が g≤0 の中にある → 条件は関係なく ∇f＝0 で解ける。右：外にある → 領域の境界の上で、f の等高線と境界が接する所が最適解。そこでは ∇f と ∇g が逆向き：∇f＝−α∇g（α＞0）

2つの場合を1本にまとめるのがラグランジュ関数と KKT 条件。

ラグランジュ関数と KKT 条件
\(L(x,y,\alpha)=f(x,y)+\alpha\,g(x,y)\) \(\nabla L=0,\quad \alpha\ge0,\) \(\quad\alpha\,g(x,y)=0,\quad g(x,y)\le0\)

\(\alpha\,g=0\) だから、\(\alpha=0\) か \(g=0\) のどちらか。\(\alpha=0\) なら \(\nabla L=\nabla f=0\)（左の場合）。\(g=0\) なら境界の上で \(\nabla f=-\alpha\nabla g\)（右の場合）。KKT 条件は2つの場合を両方含んでいる。\(\alpha\) をラグランジュ乗数と呼ぶ。

なぜ \(\alpha g=0\)（相補性）？

条件が効いていない（最小点が内側）なら、条件の重み \(\alpha\) は 0 でいい。条件が効いている（境界ぴったりで止められている）なら \(g=0\)。どちらか片方は必ず 0 になる。SVM ではこれが「サポートベクトル以外は \(\lambda=0\)」の正体になる。

SVM に当てはめる

条件が \(n\) 本あるので、ラグランジュ乗数も \(\lambda_1,\dots,\lambda_n\) の \(n\) 個。

\[L=\frac12\lVert\vw\rVert^2-\sum_{k=1}^{n}\lambda_k\bigl(b_k(w_0+\vw^t\vx_k)-1\bigr)\]

条件は「\(\ge0\)」の向き（\(b_k(w_0+\vw^t\vx_k)-1\ge0\)）なので、「\(\le0\)」の形に直すとマイナスが付く。そのため和の前がマイナスになる。

KKT 条件（解 \(\vw,w_0\) が存在するための必要十分条件）：

\[\begin{aligned}&\frac{\partial L}{\partial\vw}=\mathbf{0},\quad \frac{\partial L}{\partial w_0}=0,\quad \lambda_k\ge0,\\&b_k(w_0+\vw^t\vx_k)-1\ge0,\\&\lambda_k\bigl(b_k(w_0+\vw^t\vx_k)-1\bigr)=0\end{aligned}\]
双対問題：λ だけの問題にする

KKT 条件の最初の2つを計算すると

\[\begin{aligned}\frac{\partial L}{\partial\vw}=\mathbf{0}\ &\Rightarrow\ \vw=\sum_{k=1}^{n}\lambda_kb_k\vx_k\\\frac{\partial L}{\partial w_0}=0\ &\Rightarrow\ \sum_{k=1}^{n}\lambda_kb_k=0\end{aligned}\]

1つ目で \(\vw\) が「学習パターンの足し算」になった（第2回の \(\vw=\sum\alpha_kb_k\vx_k\) とそっくり）。これを \(L\) に代入すると、\(\vw\) と \(w_0\) が消えて \(\lambda\) だけの式になる。

\[\begin{aligned}L(\vlam)&=\sum_{k=1}^{n}\lambda_k-\frac12\lVert\vw\rVert^2\\&=\sum_{k=1}^{n}\lambda_k-\frac12\sum_{i=1}^{n}\sum_{j=1}^{n}\lambda_i\lambda_jb_ib_j\,\vx_i^t\vx_j\end{aligned}\]
代入の計算（自分でやってから開く。ヒント：\(L\) を3つの和に分ける）
  1. \(L=\frac12\lVert\vw\rVert^2-\sum_k\lambda_kb_k\vw^t\vx_k\) \(-\,w_0\sum_k\lambda_kb_k+\sum_k\lambda_k\)かっこを外して、和を3つに分けただけ
  2. 2つ目の和 \(=\vw^t\sum_k\lambda_kb_k\vx_k=\vw^t\vw=\lVert\vw\rVert^2\)\(\vw\) はどの \(k\) にも共通なので外に出せる。残りは \(\vw\) そのもの
  3. 3つ目の和は \(\sum_k\lambda_kb_k=0\) なので消える\(\partial L/\partial w_0=0\) の結果
  4. \(L=\frac12\lVert\vw\rVert^2-\lVert\vw\rVert^2+\sum_k\lambda_k\) \(=\sum_k\lambda_k-\frac12\lVert\vw\rVert^2\)足し引きしただけ
  5. \(\lVert\vw\rVert^2=(\sum_i\lambda_ib_i\vx_i)^t(\sum_j\lambda_jb_j\vx_j)\) \(=\sum_i\sum_j\lambda_i\lambda_jb_ib_j\vx_i^t\vx_j\) ∎和どうしの内積は、全部の組の内積の和
SVM の双対問題

1つは、条件が簡単に書けるから（\(\lambda\ge0\) と等式1本だけ）。もう1つは、データが内積 \(\vx_i^t\vx_j\) の形でしか出てこないから。この内積を別の関数に取り替えると、境界を曲げられる（第7回のカーネル法）。

サポートベクトル：境界を決めているのは一部の点だけ

双対問題の解を \(\vlam^*=(\lambda_1^*,\dots,\lambda_n^*)\)（5.38）とすると、重みは \(\vw^*=\sum_k\lambda_k^*b_k\vx_k\)（5.39）。KKT 条件の \(\lambda_k(b_k(\cdots)-1)=0\) から、各パターンはどちらかになる（5.40、5.41）。

\(\lambda_k^*\)\(b_k(w_0^*+\vw^{*t}\vx_k)-1\)意味
\(>0\)\(=0\)マージンの端の線の上にいる ＝ サポートベクトル
\(=0\)\(>0\)外側にいる。\(\vw^*\) に効かない

サポートベクトル（＝\(\lambda_k^*>0\) の学習パターン）は、重みの決定に寄与し、決定境界に最も近い。それ以外の点を消しても、答えは変わらない。

サポートベクトルと w₀
\(\vw^*=\sum_k\lambda_k^*b_k\vx_k\)（足すのは \(\lambda_k^*>0\) の点だけ） \(w_0=b_s-\vw^{*t}\vx_s\)（\(\vx_s\) はサポートベクトル）

\(w_0\) の式は、サポートベクトルでは \(b_s(w_0+\vw^t\vx_s)=1\)、両辺に \(b_s\) を掛けると \(b_s^2=1\) なので \(w_0+\vw^t\vx_s=b_s\)、から出る。

第2回のパーセプトロンも \(\vw=\sum\alpha_kb_k\vx_k\) だった（係数が0でない点＝寄与ベクトル）。SVM ではそれが \(\lambda\) に変わり、0 でない点がサポートベクトル。違うのは、SVM の答えは順序に関係なく1つに決まること。

SVM の特長（教科書 p.83）
  1. 汎化能力が高い ← マージン最大化
  2. 複雑な決定境界が表現できる ← カーネルの利用（第7回）
  3. 大域的最適解（＝全体で一番いい解）への収束が保証される ← 凸二次計画問題なので谷が1つ
  4. 解が一意に決定される ← 同上。パーセプトロン（順序で変わる）との大きな違い

  2. SVM はマージンを最大化して汎化能力の向上を目指す
  3. 線形 SVM（線形分離できる場合）は凸二次計画問題として表現でき、ラグランジュの未定乗数法で解く。より簡単に解ける双対問題が得られる

確認\(\vx_1=(\frac12,\frac12)^t,\ b_1=1\)、\(\vx_2=(-\frac12,-\frac12)^t,\ b_2=-1\) で SVM を手計算し、\(\lambda,\ \vw,\ w_0\)、マージン \(R\) を求めよ
  1. \(\lambda_1-\lambda_2=0\) → \(\lambda_1=\lambda_2\)
  2. \(\vw=\lambda_1(\frac12,\frac12)+\lambda_2(\frac12,\frac12)=(\lambda_1,\lambda_1)\)
  3. \(L=2\lambda_1-\frac12(\lambda_1^2+\lambda_1^2)=2\lambda_1-\lambda_1^2\)、\(\dfrac{dL}{d\lambda_1}=2-2\lambda_1=0\) → \(\lambda_1=\lambda_2=1\)
  4. \(\vw=(1,1)\)、\(g(\vx_1)=w_0+\frac12+\frac12=1\) → \(w_0=0\)。\(g(\vx)=x_1+x_2\)

\(R=2/\lVert\vw\rVert=2/\sqrt2=\sqrt2\)（2点の距離 \(\sqrt2\) と一致 ✓）。点を半分にすると \(\lambda\) は4倍、\(\vw\) は2倍、\(R\) は半分になる。

線形分離できないとき：スラック変数 ξ

ハードマージンの条件 \(b_k(w_0+\vw^t\vx_k)\ge1\) は、1点でも反対側に入り込むと満たせない。そこで点ごとに「はみ出してもいい量」\(\xi_k\ge0\) を用意する。

\[b_k(w_0+\vw^t\vx_k)\ \ge\ 1-\xi_k\qquad(\xi_k\ge0)\]

\(\xi_k\) をスラック変数（＝条件をゆるめる「遊び」の量）と呼ぶ。条件を満たす一番小さい値は \(\xi_k=\max(0,\ 1-b_kg(\vx_k))\)。

\(\xi_k\)どこにいる？
\(0\)マージンの外（ルールどおり）
\(0<\xi_k\le1\)マージンの内側に入ったが、境界の正しい側
\(\xi_k>1\)境界の反対側 ＝ 誤識別
ソフトマージンとスラック変数（g＝x₁−x₂）
A（ω₁）は g＝0.4：内側に入ったが正しい側 → ξ＝1−0.4＝0.6。B（ω₁）は g＝−0.7：境界を越えて反対側 → ξ＝1−(−0.7)＝1.7（誤識別）
ソフトマージンSVM：はみ出しに罰金

\(\xi_k\) を大きくすれば、どんな \(\vw\) でも条件を満たせてしまう（マージン \(R\) もいくらでも大きくできる）。それで良いのか？ → 良くない。はみ出した量にも罰金を課して、一緒に最小化する。

ソフトマージンSVM
条件：\(b_k(w_0+\vw^t\vx_k)\ge1-\xi_k,\quad \xi_k\ge0\) 目的：\(\min\ L=\frac12\lVert\vw\rVert^2+c_{pe}\sum_{k=1}^{n}\xi_k\)

\(c_{pe}\) は誤識別に対する重み係数（＝はみ出し1単位あたりの罰金の重さ）。学習の前に人が決める値で、こういう値をハイパーパラメータと呼ぶ。

\(c_{pe}\)罰金結果
大きい重いはみ出しを許さない → ハードマージンに近い（マージンは狭め）
小さい軽いはみ出しに寛容 → マージンは広め

これまでの（はみ出しを許さない）ものをハードマージンSVM、ξ を入れたものをソフトマージンSVMと呼ぶ。

SVM を使う上での留意点
  1. そのままでは3クラス以上の識別ができない（2クラス用を組み合わせる）
  2. 凸二次計画法を解くための計算量に注意が必要（学習パターン数 \(n\) が増えると、\(n\times n\) の \(\mathbf{H}\) を扱うので重い）
  3. 重み係数 \(c_{pe}\) はあらかじめ設定する必要がある（ハイパーパラメータ）
  4. クラスによって学習パターンの数に大きな偏りがある場合に注意が必要（クラスごとに \(c_{pe}\) を変えるなど）
試験で取る（第6回のまとめ）
  1. SVM はラグランジュの「未定乗数法」で解く。「双対問題」にすると原問題より「解きやすい形」になる
  2. サポートベクトル：決定境界の決定に「寄与する」学習パターン。解法の中で「\(\lambda>0\)」となるものに対応
  3. 線形分離できる → 「ハードマージン」SVM ／ できない → 「ソフトマージン」SVM（「スラック変数」と、誤識別に対する「重み係数」を導入）
  4. 去年は「\(c_{pe}\) は何と呼ばれるか（ハイパーパラメータ）」「留意点として正しいもの」が出た

第7回 ── 内積を取り替えて、境界を曲げる

SVM の境界を曲げたい。でも、ものすごく高い次元の \(\vphi(\vx)\) を毎回作るのは重い。どうする？

この章の流れ
非線形写像 φΦ空間へ写す→双対問題は内積だけhᵢⱼ＝bᵢbⱼ φᵗφ→カーネル関数k(x,y)＝φ(x)ᵗφ(y)→主なカーネル線形・多項式・RBF・シグモイド→ハイパーパラメータγ・d・r
双対問題には、データが内積の形でしか出てこない。その内積を関数 \(k\) に取り替えれば、\(\vphi\) を作らずに Φ空間で SVM ができる。

前の回の弱点：線形SVM（ハード／ソフト）の境界は直線。円の内側と外側のようなデータでは、SVM でも100%の精度は出ない。

ゴール
  1. 双対問題の内積をカーネル関数に取り替えればいい理由を言える
  2. 例1の \(\vphi\) で \(\vphi(\vx)^t\vphi(\vy)=(\vx^t\vy)^2\) を展開して示し、数値で検算できる
  3. 4つのカーネルの式とハイパーパラメータ、\(\gamma\) を変えたときの境界の変化を言える
非線形写像と SVM を組み合わせる

第4回と同じく、\(\vx=(x_1,\dots,x_d)^t\) を非線形写像 \(\vphi(\vx)=(\phi_1(\vx),\phi_2(\vx),\dots)^t\) で写してから SVM をかける。円の例なら、原空間の SVM では100%の精度は出ないが、Φ空間の SVM なら100%を達成できる。

双対問題（→05）で、データが出てくるのは \(\mathbf{H}\) の要素だけだった。\(\vx\) を \(\vphi(\vx)\) に置き換えると

\[h_{ij}=b_ib_j\,\vx_i^t\vx_j\ \ \longrightarrow\ \ h_{ij}=b_ib_j\,\vphi(\vx_i)^t\vphi(\vx_j)\]

（教科書 (5.89) → (5.109)）。必要なのは \(\vphi\) そのものではなく、その内積だけ。

カーネル関数と非線形SVM
\(k(\vx,\vy)=\vphi(\vx)^t\vphi(\vy)\) \(h_{ij}=b_ib_j\,k(\vx_i,\vx_j)\) \(g(\vx)=\sum_k\lambda_kb_k\,k(\vx_k,\vx)+w_0\)

カーネル関数 \(k(\vx,\vy)\) を定めれば、非線形写像 \(\vphi\) 自体は未定義でもOK。カーネル関数を使う SVM を非線形SVMと呼ぶ。識別関数も \(\vw^t\vphi(\vx)+w_0=\sum_k\lambda_kb_k\vphi(\vx_k)^t\vphi(\vx)+w_0\) なので、やはり \(k\) だけで計算できる。

例1：\((\vx^t\vy)^2\) は3次元への写像の内積

2次元の \(\vx=(x_1,x_2)^t,\ \vy=(y_1,y_2)^t\) を、3次元に写す（\(d=2,\ D=3\)）。

\[\vphi(\vx)=\left(x_1^2,\ x_2^2,\ \sqrt2\,x_1x_2\right)^t\tag{6.2}\]
\[\begin{aligned}\vphi(\vx)^t\vphi(\vy)&=x_1^2y_1^2+x_2^2y_2^2+2x_1x_2y_1y_2\\&=(x_1y_1+x_2y_2)^2=(\vx^t\vy)^2\end{aligned}\]

（6.3〜6.5）。だから \(k_1(\vx,\vy)=(\vx^t\vy)^2\) はカーネル関数（6.6）。

数値で検算：\(\vx=(1,2),\ \vy=(3,1)\) → \(\vx^t\vy=5\) → \((\vx^t\vy)^2=25\)。

写してから計算すると \(\vphi(\vx)=(1,\ 4,\ 2\sqrt2)\)、\(\vphi(\vy)=(9,\ 1,\ 3\sqrt2)\)、内積 \(9+4+2\sqrt2\cdot3\sqrt2=9+4+12=25\) ✓。

カーネルを使うと何が得？

3次元のベクトルを2本作って内積を取る代わりに、2次元の内積を1回してから2乗するだけで済む。次元が大きいほどこの差が効く（例2では10次元、RBF カーネルでは無限次元に相当）。「高次元空間での演算を、低次元の原空間での演算で代えられる」のがカーネル法の核心。

例2：\((1+\vx^t\vy)^3\) は10次元

2次元から10次元への写像（\(d=2,\ D=10\)）

\[\begin{aligned}\vphi(\vx)=\bigl(&1,\sqrt3x_1,\sqrt3x_2,\sqrt6x_1x_2,\\&\sqrt3x_1^2,\sqrt3x_2^2,\sqrt3x_1^2x_2,\\&\sqrt3x_1x_2^2,x_1^3,x_2^3\bigr)^t\end{aligned}\tag{6.7}\]

の内積は \(\vphi(\vx)^t\vphi(\vy)=(1+\vx^t\vy)^3\)（6.8）。だから \(k_2(\vx,\vy)=(1+\vx^t\vy)^3\)（6.9）もカーネル関数で、後の多項式カーネルにあたる。

同じ \(\vx=(1,2),\ \vy=(3,1)\) で \((1+5)^3=216\)。10次元のベクトルを作って内積を取っても 216 になる（検算済み）。10個の成分を作る手間が、足し算1回と3乗1回で済む。

例3：\(D=d^2\) 次元でも同じカーネルになる

\(\vphi(\vx)=(x_ix_j)_{i,j=1}^{d}\)（6.10）＝すべての組 \(i,j\) について \(x_ix_j\) を並べた \(d^2\) 次元のベクトル。\(d=2\) なら \(\vphi(\vx)=(x_1^2,\ x_1x_2,\ x_2x_1,\ x_2^2)^t\)（6.11）。

\[\begin{aligned}\vphi(\vx)^t\vphi(\vy)&=\sum_{i,j=1}^{d}x_ix_jy_iy_j\\&=\sum_{i=1}^{d}x_iy_i\sum_{j=1}^{d}x_jy_j=(\vx^t\vy)^2\end{aligned}\]

（6.12〜6.15）。数値：\(\vphi(\vx)=(1,2,2,4)\)、\(\vphi(\vy)=(9,3,3,1)\) → \(9+6+6+4=25\) ✓。

例1（3次元）と例3（4次元）は違う \(\vphi\) なのに、同じカーネル \((\vx^t\vy)^2\) になる。\(\vphi\) は1つに決まらないが、カーネルさえ決めれば SVM は動く。だから \(\vphi\) は未定義でいい。

記述
確認A. SVM で、主問題ではなく双対問題を解く理由を2つ書け
  1. 条件が簡単に書ける（\(\vlam\ge0\) と \(\vlam^t\vb=0\) だけ。主問題は不等式が \(n\) 本）
  2. データが内積 \(\vx_i^t\vx_j\) の形でしか出てこないので、内積をカーネル関数に取り替えて非線形SVM にできる
確認B. サポートベクトルとは何か。KKT 条件と結びつけて説明せよ

KKT 条件の \(\lambda_k\bigl(b_k(w_0+\vw^t\vx_k)-1\bigr)=0\) から、各学習パターンは「\(\lambda_k=0\)」か「\(b_k(w_0+\vw^t\vx_k)=1\)（マージンの端の線の上）」のどちらか。

\(\lambda_k^*>0\) となるパターンがサポートベクトルで、決定境界に最も近く、\(\vw=\sum\lambda_k^*b_k\vx_k\) の決定に寄与する。\(\lambda_k^*=0\) のパターンは重みに効かない。

確認C. カーネル法の利点を、「高次元」「内積」という言葉を使って説明せよ

非線形写像で高次元空間に写せば複雑な決定境界を表現できるが、SVM（双対問題）で必要なのは写した先の内積だけ。カーネル関数 \(k(\vx,\vy)=\vphi(\vx)^t\vphi(\vy)\) を使えば、高次元での内積の計算を原空間での計算で代えられ、写像 \(\vphi\) 自体を定める必要もない。

確認D. SVM を利用する上での留意点を4つ書け
  1. そのままでは3クラス以上の識別ができない
  2. 凸二次計画法を解く計算量に注意が必要
  3. 重み係数 \(c_{pe}\)（やカーネルの \(\gamma\) など）はあらかじめ設定する必要がある（ハイパーパラメータ）
  4. クラスによって学習パターンに大きな偏りがある場合に注意が必要（クラスごとに \(c_{pe}\) を変えるなど）

確認E. パーセプトロンとハードマージンSVM で、決定境界の決まり方はどう違うか

パーセプトロンは、間違えたパターンを足していき、全部正しく分けられた所で止まる。どこで止まるかはパターンを与える順序しだいで、境界は一意に決まらず、境界すれすれの点が残ることもある。

ハードマージンSVM は、全部を正しく分ける境界の中からマージン \(R=2/\lVert\vw\rVert\) が最大のものを、凸二次計画問題として解く。解は一意で、サポートベクトルだけで決まり、汎化能力が高いと期待できる。
